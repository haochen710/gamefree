# 仙途 · 修仙放置游戏

一款跑在浏览器里的**修仙题材放置（idle）游戏**，玩法参考
[猫国建设者 / Kittens Game](https://github.com/bloodrizer/kitten-game)：
从打坐引气入体开始，个人游历、钻研技术、建洞府、**排建造队列**、**金丹开宗**、收弟子、
**在六大区域 96 个小区域里探索 150 处秘境（含六处特产秘境，也可以掌门亲自去；
资源富集区的秘境要先花资源立阵眼才能探）**、
**炼丹炼器有成功率、器物会给弟子配装而且会用坏（6 件可携带）**、
**大境界突破必须服一颗对应境界丹（掌门与弟子都是）**、
**在纪年里过日子（一年 = 现实 8 分钟）**、在路上遇见商队与各色 NPC 并攒下善恶值、
**应付找上门的宗门事件（匪徒围攻、兽潮、魔修叩山 —— 靠三座宗门大阵挡）**、
**在元婴期后修五行与时空感悟（时空穿梭、空间戒指）**、
**把基础资源合成灵液 / 精金 / 阵枢三种进阶资源**、
**把宗门养到上千名弟子（一品 100 人 → 九品 2,048 人）**、
种植灵材、经营商行、炼丹炼器、经营宗门建筑与大比，最终举霞飞升。

**纯前端，没有后端、没有数据库、没有账号。** 存档就存在你自己的浏览器里。
界面是**水墨黑白风**（全站唯一保留的颜色是警示红）。

## 快速开始

### 方式一：双击启动（推荐）

双击项目根目录下的 **`启动游戏.cmd`** 就行。它会自动：

- 切换到项目目录（不管从哪里双击都不会找错地方）
- 检查环境（缺 node_modules 会自动安装依赖）
- 如果服务器已经在跑，就直接打开浏览器，不会重复启动
- 等服务器真正就绪后再自动开浏览器（轮询，不是傻等固定几秒）
- 显示中文提示和访问地址

关闭服务器：在弹出的命令行窗口里按 **Ctrl+C**。

> ⚠️ **不要用记事本/VS Code 修改 `启动游戏.cmd` 后存成 UTF-8。**
> cmd.exe 是按当前代码页（中文 Windows 是 GBK）解析批处理文件的，
> 存成 UTF-8 会让中文乱码，甚至整行被误判成命令。
> 这个文件同时必须是 **CRLF 换行**（LF 会让 `if (...)` 多行块解析失败）。
> 仓库里的 [`.gitattributes`](.gitattributes) 已经对 `*.cmd` 关闭了所有转换，
> 保证 clone 下来就是正确的格式。

### 方式二：命令行

**第一步是先进入项目目录**（下面是本项目的位置，换成你自己的）：

```bash
cd D:\dsh_test\gamefree
```

然后：

```bash
pnpm install
```

```bash
pnpm dev
```

> ⚠️ **不要把命令后面的中文说明一起复制进终端。**
> `#` 在 cmd 和 PowerShell 里都不是注释符，`pnpm install # 安装依赖` 会被
> pnpm 理解成"安装一个名叫 `#` 的包"，报
> `ERR_PNPM_SPEC_NOT_SUPPORTED_BY_ANY_RESOLVER`。

启动后打开 **http://localhost:5173/gamefree/**（注意结尾的 `gamefree/` 路径，见下方说明）。

其他命令：

| 命令 | 作用 |
|---|---|
| `pnpm dev` | 开发服务器，改代码自动热更新 |
| `pnpm build` | 类型检查 + 打包到 `dist/` |
| `pnpm preview` | 本地预览打包结果，用来验证"上线后会怎样" |
| `pnpm typecheck` | 只跑 TypeScript 类型检查 |
| `pnpm smoke` | 冒烟测试：渲染整个界面 + **1170 项**逻辑校验 |
| `pnpm simulate` | **数值模拟器**：自动玩 30 天并输出时间线，调平衡用 |

> 用的是 pnpm。如果你只有 npm，把命令里的 `pnpm` 换成 `npm run` 也能跑，
> 但需要删掉 `pnpm-lock.yaml` 重新 `npm install`。

## 玩法

界面上有**十个页签**：**修行 / 探索 / 宗门 / 建筑 / 工坊 / 丹器 / 商行 / 灵植 / 感悟 / 洞府**。
导航下面的**左侧固定栏是资源与材料**（需求 2 要求它不许压在别的模块上方），
右边才是各个页签的内容。

> 🆕 **这一版把页签从 7 个扩到 10 个**（需求 5 / 6 / 7 / 8），三块内容各自独立成页：
> **建筑**（建造 + 建造队列，原来在「洞府」页）、
> **工坊**（合成 · 精炼 + 钻研 + 图纸，原来在「修行」页）、
> **商行**（原来在「灵植」页）。
> 于是「洞府」页**只剩存档**（导出 / 导入 / 重开），
> 「修行」页只剩打坐 / 仆役 / 遭遇 / 境界 / 季节 / 飞升，
> 「灵植」页只剩种植。
> 排法按"一天里点开的频率"：修行 → 探索 → 宗门 → 建筑 → 工坊 → 丹器 → 商行 → 灵植 → 感悟 → 洞府。
> **只有「宗门」这一页会被灰掉**（未开宗时标「未开宗」）——
> 探索 / 丹器 / 工坊 / 商行开宗前都不灰，因为靠游历与普通探索就能拿到材料。

几条一眼就该知道的界面约定：

- **纪年在页头右上角**（`第 N 年 · X季 · 今年 N%` + 一条进度条）—— 任何页面都看得见，
  它和左边那排读数**是同一层的配色**（没有白底、没有边框，只有左侧一条分隔线）；
- **整体框架会跟着屏幕变宽**：窗口越宽、内容区越宽（上限 1720px、两侧各留 2%），
  左边的资源栏固定 196px；
- **资源栏可以按类折叠**：基础资源 / 基础材料 / **稀有材料（默认收起）** / 进阶材料，
  四组各自展开收起，选择会记住（存在浏览器里，不进存档）；
- **五种基础资源下面各写着一行"照这个速度多久填满"（满仓倒计时）** ——
  已经满了写「已满」，当前没有产出写「无产出」，超过 100 天的写「很久以后」
  （不拿一个 ∞ 糊过去）；材料那一类不设上限，卡片上写死的是
  "游历 / 探索 / 种植 · 无上限"，本来就不走倒计时；
- **资源栏底下不再有季节条**（那一行已经删掉，纪年搬去了页头）；
- **全站是黑白风（水墨）**：去掉色相、只留墨与纸，
  **唯一保留的颜色是警示红**（资源不足 / 伤亡 / 危险 / 锁定 / 满仓那一类）。
  资质与稀有度也改成了灰阶，**越好的越黑** —— 所以"天灵根"看起来比"凡品灵根"更重；
- **6 块面板都能折叠**（点标题栏就能收起，选择会记住）：
  「建筑」页的**建造清单 / 建造队列**、「工坊」页的**合成 · 精炼 / 钻研 / 图纸**、
  「洞府」页的**存档**；
- **分类本身也能折叠**：「建筑」页的**十类建筑**各自一组，可分别收起
  （**开宗之前看不到「弟子居所」那一组** —— 它是空的）；
  「丹器」页里**丹方按品阶、器物也按品阶**各成一组，**还没掌握的品阶默认收起**
  并在标题上写「尚未掌握」—— 免得九品配方把你能炼的那几档挤下去。

### ☯ 修行

> 📋 **「修行」页现在有这些**：
> 左栏是 **打坐** 与 **仆役**（仆役面板底部多了一行「**批量调动**」）；
> 右栏从上到下是 **随机遭遇 / 境界 / 四季与天象 / 飞升**。
> ⚠️ **「合成 · 精炼」和「钻研 + 图纸」本轮都搬去了「工坊」页**，
> **「感悟」是一个独立页签**，所以这一页现在只剩上面这些。
> 📌 页签上的角标会告诉你"哪一页有事情可做"：
> 探索页显示在外面的队伍数、宗门页显示空闲弟子数、灵植页显示成熟地块数、
> **建筑页显示建造队列里排着的条目数**。

1. **打坐** 攒灵气，建第一座 **聚灵阵** —— 从此灵气会自动增长。
   打坐受「心神」限制（上限 20，每 6 秒回 1 点），**狂点也无法显著加速游戏**。
   🆕 **聚灵阵同时还给弟子修炼加成**（**2% × √座数**，收益递减）——
   所以"多盖聚灵阵"从这一版起是**双收益**：既产灵气，又让弟子修行更快
   （见常见问题「为什么聚灵阵越多弟子越快？」）。
2. 依次建 **灵木林**（灵木）→ **灵矿脉**（灵矿）→ **灵田**（灵草）→ **灵石矿**（灵石）。
   中期还会解锁五座**高产设施**：灵泉井、灵竹海、深脉矿洞、百草园、灵石母矿。
3. 灵气用来 **参悟小境界**（**每层 +4% 全局产量**，仙人 +10%），满层后 **突破大境界**。
   ⚠️ **本轮改动最大的一条：突破必须服一颗对应的境界丹，没有丹连试都不能试。**
   - 面板上只有一个 **「服丹突破」** 按钮；仓库里没有对应境界丹时它是灰的，
     并直接写明**缺哪一味**（例如「需化神丹（丹房炼制，或秘境掉落）」）；
   - **丹药补足差额的 62%，成功率上限 95%**（原来是一个固定的 +35%，
     以及 98% 的上限）；
   - **「失败后累积保底成功率」已经删掉** —— 既然丹药是门票，
     就不该再有第二条"不花丹药反复撞"的路；
   - 炼气 / 筑基 / 金丹期失败**没有其它代价**（灵气全额返还、可立即再试），
     元婴期起失败会 **道伤缠身**：一段时间内无法再次突破、期间产量 −25%；
     ⚠️ **但丹药无论成败都会消耗**；
   - ⚠️ **弟子的突破也吃丹药**：弟子修为攒满而仓库没丹时，他会**停在瓶颈**
     （修为不丢），宗门记事里会写「XX 修为已满YY，只差一味ZZ便可破境」，
     弟子列表上也会打一个「**缺丹**」标签。
     这是"弟子怎么不涨了"最常见的原因 —— 详见常见问题「弟子卡在瓶颈了？」。
4. **资源有储存上限**（开局灵气只能存 250，而第一次突破要 600）。
   到达上限后产量就白白溢出，所以要建 **储物建筑** 扩容：
   储物袋 → 藏宝阁 → 灵脉库房 → 须弥洞府 → 芥子乾坤 → 太虚宝库 → 周天星库 →
   混元仙藏 → 鸿蒙道藏，每级约 20 倍容量。
   （材料不受上限约束 —— 探索掉落卡上限只会让人烦躁。）

> 🌤 **纪年、季节与天象**（需求 1）：天上一直在变，而且它直接改产出。
>
> - **纪年：一年 = 现实 8 分钟，一季 = 2 分钟**。显示成「**第 N 年 · X季**」，
>   在**页头右上角**（`第 N 年 · X季 · 今年 N%` + 进度条）与「修行」页的季节面板上
>   各有一处；年份是从"修行时长"推出来的，所以**飞升之后不会归零**。
>   同一个日历还决定了**弟子寿元与弟子修为**、以及**宗门大比的周期** ——
>   所以"一年有多长"是本作最大的一个旋钮（见 [BALANCE.md](BALANCE.md) 第二十二节）。
> - **四季**每 **2 分钟**换一次，每一季**同时有加成与减益**：
>   春 灵草 +45% / 寒玉 −25%，夏 灵气 +30% / 寒玉 −40%，
>   秋 灵矿 +35% / 灵气 −10%，冬 寒玉 +50% / 灵草 −35%。
>   没有"最好的季节"可以一直等 —— 所以"这一季该囤什么"是真的要看。
> - **天象**每约 **40 秒**判定一次（40% 概率出现），持续 **45~60 秒**，共十条，
>   分**吉 / 凶 / 双刃**：紫气东来是全局产量 +40%，灵雨让灵草灵木各 +60%，
>   血月当空让妖丹翻倍但弟子修行 −15%，弥天大雾让探索速度 −45%。
> - 影响范围**只有资源与基础材料**；稀有材料来自秘境深处，不吃季节加成。
>   **天象不会提高发现秘境的概率**（那条线只有寻宝宝盘能碰），**也不影响弟子伤亡**。
> - 完整的季节面板（当前季节进度条 + 天象详情 + 四季与天象图鉴）在「**修行**」页；
>   想随时知道年份 / 季节，看**页头右上角**那一块就行 ——
>   原来左侧资源栏下面那一条常驻的季节条已经删掉了（纪年搬去了页头）。

> 😇😈 **善恶值与随机遭遇**（需求 2）：**任何时候都可能遇到人** ——
> 开宗前在路上，**开宗之后山里的事与路上的事都会找上门来**。每一个都得做选择。
>
> - 每个选择都会改变你的 **善恶值**（一条从 **−100（大恶）到 +100（大善）** 的轴，
>   分**大善 / 行善 / 中立 / 作恶 / 大恶**五档）。
> - **恶行越高，突破越容易挨天雷**：恶行拉满时突破成功率 **−35%**，
>   而且**参悟小境界也会被打断**（灵气照扣、落 2 分钟道伤）。
>   不过成功率有 **15% 的下限** —— 作恶会更难，但不会变成死路。
> - **恶行低到 −30 以下**，遭遇里才会出现 **抢劫** 选项：一次能拿大量材料、
>   甚至稀有材料（仙玉、混沌紫气），但**成功率一律不高**（40%~55%），
>   失败要挨 3~12 分钟的道伤。有几条不必掷骰（比如抢一个重伤散修的储物袋）。
> - **善行越高，探索产出越好**：善行拉满时**秘境 / 普通探索 / 掌门独自探秘境**
>   的产出 **+30%**（游历不吃这条）。
> - **每条遭遇在屏幕上只停 30 秒**：玩家事件与普通宗门事件到点**自动消失、没有影响**；
>   而**宗门被进攻**那三条（🏴 匪徒围攻山门 / 🐗 兽潮来袭 / 👹 魔修叩山）
>   **到点会照常结算** —— 所以卡片上会直接写清"宗门防御 X% · 预期受伤弟子 N 人"。
> - 遭遇面板（「修行」页）会实时把上面两条后果算给你看，
>   左侧资源栏也常驻一行善恶值，**有待选遭遇时会显示一个「遇」字角标**。
>
> 详见 [BALANCE.md](BALANCE.md) 第二十三节（九条玩家遭遇 + 六条宗门事件 +
> 进攻结算公式 + 三座宗门大阵的减伤对照表）。

### 🧘 感悟（元婴期开放的独立页签）

> 🌌 **感悟（五行 + 时空，需求 3）**：**元婴期**解锁这个模块 ——
> 它是**独立的一个页签**（「感悟」，排在「灵植」之后、「洞府」之前），不再挂在修行页里。
> 七条道、每条 **九个大阶段 × 十个小阶段 = 90 阶**，一阶一阶修上去：
>
> - **五行五条道**（⚔ 金 / 🌳 木 / 💧 水 / 🔥 火 / ⛰ 土）各绑定一种基础材料
>   （玄铁 / 灵蚕丝 / 寒玉 / 地火髓 / 妖丹），**每阶 +1.5%、满阶 +135%**。
>   它和季节是**两个独立乘区**，所以"冬天灵草 −35%"不会被五行修满抹平
>   （修满之后冬天仍然是 `0.65 × 2.35 = +52.75%`，而不是 +100%）。
> - **⏳ 时间大道**（化神期解锁）：**每 5 游戏年可以时空穿梭一次**，
>   一次跳 **6 ~ 50 年**（随阶数增长），**把这段时间里的一切一次性结算** ——
>   产出、钻研、灵植、秘境冷却、弟子修炼全都往前走。
>   ⚠️ **代价是弟子会真的老去**：寿元不够的会在穿梭里坐化。
> - **🌀 空间大道**（化神期解锁）：每阶 **+0.5%** 探索产出，
>   还能做 **空间戒指**（每枚再 **+5%**，最多 9 枚）——
>   第 n 枚要求空间大道 ≥ n×10 阶，越往后越贵（第 9 枚要 274 亿灵气 + 10,975 阵枢）。
> - **感悟要花大量资源与时间**：一阶 45 秒起（`45 × 1.045^阶`），
>   花费横跨**灵气 / 灵草 / 灵矿 / 灵石**，并且每 5 阶还要吃**阵枢**（进阶资源）。
>
> 详见 [BALANCE.md](BALANCE.md) 第二十四节。

### 🗺 探索（地图 + 秘境 + 普通探索 + 游历）

5. **地图是三层结构**：**6 个大区域**（东部群山 / 南疆 / 西漠 / 北境 / 中州 / 无垠海），
   每个大区域 **16 个小区域**，共 **96 个小区域**；
   每个小区域里再挂着 **1~3 处秘境**，共 **150 处**。
   **初始只能探索东部群山**（大区域的解锁境界依次是
   炼气 / 筑基 / 金丹 / 元婴 / 化神 / 炼虚），
   你的洞府在**东部群山**的青石谷，一开始只走得动附近四个小区域 ——
   小区域的门槛等于「大区域基调 + 每 4 格升一档」，
   **境界越高越能飞，能去的小区域就越多**。
   探索页顶部会直接告诉你三件事：
   `探索距离 N 里 · 可达 X/96 小区域 · 已发现 Y/150 秘境`。
   灵舟坊还能再给 **+25% 探索距离**。
6. **每个大区域只有一处「资源富集区」**（4×4 网格的最后一格，界面上带「富集」角标）：
   它有 **3 处秘境**（别处只有 1~2 处）、**境界门槛再高 4 档**，
   而且里面**有一处特产秘境** —— 专产该大区域的独有材料
   （妖丹 / 龙血 / 星辰砂 / 太阴玄晶 / 仙玉 / 混沌紫气），
   **该特产必定掉落、数量还 ×3**。想要大量龙血，就得把境界推到南疆的「龙骸血池」。
   ⚠️ **富集区里的秘境还要先"开启"才能探**（需求 1：「资源富集区的秘境开启需要花费一定资源」）：
   发现之后卡片上是「**🔯 尚未开启**」+ 一份花费清单（灵气 / 灵石 / 灵矿 + **🔯 阵枢**），
   点「**耗费资源开启**」把阵眼立起来，才派得出队伍。
   - **只有资源富集区的 18 处秘境要开**（6 处富集区 × 每处 3 秘境），其余 132 处发现即可探；
   - 越深越贵，而且**特产秘境要贵 2.5 倍**：第 5 档富集区里三处分别是
     **33 / 44 / 55 个阵枢**（特产那处最贵，灵气 1,280 万），
     第 9 档则是 **643 / 858 / 1,072 个**（灵气最高 13.42 亿）；
     **18 处全开合计 7,364 个阵枢** —— 比三座宗门大阵的 5,850 还多，所以是"挑着开"而不是清清单；
   - ⚠️ **必须先"发现"才能"开启"** —— 没探索出来的地方连阵眼都立不了。
     所以模拟器 30 天里只开成了 1 处，**这不是开启功能没生效**（见常见问题「富集区的秘境为什么探不了？」）。
7. **150 处秘境全部靠探索发现**：它们不再是"攒够材料就自动出现"，而是
   **弟子探索或掌门游历时随机发现**（基础 **15%**）。
   发现后**永久固定**在地图上，不会因为材料被花掉而消失。
   开局只有 **青石谷·药圃** 是已知的。

   **150 处秘境的数值是"生成"出来的，不是一条条手写的**：
   小区域的境界门槛决定档次（**门槛 + 1 = 1~9 档**），档次决定推荐战力、时长、冷却、
   伤亡率、人数区间、种子稀有度、图纸概率与宗门品阶门槛；
   每个小区域里第几处秘境决定它的**路数**（灵草 / 灵矿 / 妖兽 / 遗迹 / 寒霜 / 虚空 / 天界）
   与名字后缀（药圃 / 矿窟 / 兽巢 / 古殿 / 冰窟 / 虚空裂隙 / 云台）。
   想调平衡只改那两三张表就行。
8. **普通探索**（🔍）：**一个小区域里还有没被发现的秘境时**，就能对它做普通探索 ——
   这是需求里的原话「每个小区域在未发现秘境时只能普通探索」。
   - **必定**带回基础材料（**1~2 种**，数量随机）；
   - **30%** 概率带回稀有材料；
   - 也有机会**发现新秘境**（和探秘境共用同一套发现概率与硬保底）；
   - **没有冷却、也不会折损弟子**，最多派 4 人，心得只有探秘境的一半；
   - **门槛按「大区域」算，不按小区域自己的档次**（需求 5 修的就是这个）：
     只要境界够走到这个**大区域**（东部群山炼气 / 南疆筑基 / 西漠金丹 /
     北境元婴 / 中州化神 / 无垠海炼虚），**整片大区的小区域都能做普通探索** ——
     以前用的是小区域自己的门槛，于是"除了最前面几个小区域，其它都点不动"。
     秘境本身该有的境界 / 战力 / 开启门槛**一个都没放宽**；
   - **掌门可以亲自去**（卡片底部的「掌门亲往」）：不占弟子、**不占队伍名额**、
     不会死人，而且**开宗前就能出门**；代价是时长 ×1.25、**基础材料减半**
     （稀有材料那一侧是 **30%**，与派队伍同概率 ——
     详见下面第 15 条与常见问题「掌门亲往和派队伍有什么区别？」）；
     ⚠️ **出门不再扣产量**（旧版"掌门在外时全局产量 −45%"整条删掉了，
     见常见问题「出门游历会掉产量吗？」）；
   - 但它和探秘境**抢的是同一批队伍名额**（**掌门亲往不占名额**）——
     所以派队伍的定位是"**把新区域打开**"，不是"替代刷秘境"。
     秘境那边没得打的时候再出门开图，是更划算的顺序；
   - 🆕 **可以挂机循环**：卡片底部有一个「**循环 N 次**」输入框（**1~30**）。
     普通探索**没有冷却**，所以它做完一趟就**原地重排**、队员不回池，
     最多连做 30 趟；次数做完之后队员才回到空闲。

   卡片上会写清「此地还有 N 处秘境没找到」以及"无冷却 / 无伤亡"这两条；
   地图上能普通探索、但秘境还到不了的小区域，格子上会写「**可探查 · 秘境需X**」。
9. **想提高发现概率只有一条路：寻宝宝盘**（🧭 器物，**七品炼器**才能铸，
   材料超稀有 —— 含混沌紫气 ×12）。每持有一面 **+4%**，
   但**每名弟子只能持有一件**（生效件数 = min(持有数, 弟子数)），
   所以想堆概率就得同时有弟子和材料。
   **山门 / 通天塔 / 照天镜都不再加发现概率了** ——
   它们改成了全局产量 +2%/座、秘境产出 +15%/座、探索速度 +12%/座。
   早先五个来源（建筑 + 探索距离 + 队伍人数）全挤在 75% 的封顶下面，
   后期几座建筑之间完全没有区分度，这就是这一版要修的问题。
10. **运气差也不会卡死**：连续 **10 次**没发现，第 **11 次**探索**必然**发现一处
    （硬保底）。它是**独立于概率公式**的另一条机制，所以
    「发现概率只有寻宝宝盘一个来源」这句话是成立的。这个计数会存档。
    探索页顶部会实时写明：当前发现概率、宝盘加成、以及"还差几次触发硬保底"
    （或"下一次探索必定发现"）。
11. **每次探索后有冷却，而且秘境越深、时长与冷却都越长**：一档秘境 90 秒 → 最深处的
    「上界云台·虚空裂隙」**5,040 秒（84 分钟）**，同一小区域里越靠后的秘境冷却再 +20%/位。
    单趟时长也是同一套曲线：一档 **120 秒** → 九档基准 **5,600 秒（93 分钟）**、
    最深处 **7,280 秒（约 2 小时）**。
    深了之后"每一趟"都要占住一支队伍小半个钟头 ——
    冷却是为了逼你横向铺开去找新秘境，而不是反复刷同一处。
    🆕 **可以让队伍循环探索（1~30 次）**：秘境卡片上有一个「**循环 N 次**」输入框。
    它的实现方式值得知道一下 —— **下一趟不是"立刻再来"，而是"原地等完冷却再出发"**
    （内部是把这一趟的进度设成**负数**，等它涨回 0 正好是冷却走完），
    所以**循环不会绕过冷却**；队员在这期间**一直算"探索中"**，不会回到空闲池里被别人派走。
    中途如果伤亡到**凑不满最少人数**（低于 `minParty`），循环就**停在那里**，队员正常回池。
    上限 **30** 是刻意定的：九档最深处一趟要 1.5 小时，挂 30 趟在现实里要跑好几天。
12. **人越多，拿到的资源越多**：每处秘境有一个人数区间（一档 1~4 人，
    九档 5~14 人），每多带一人总产量 **+40%**，且**多抽一条掉落**
    （3 条 → 最多 6 条）。代价是更多弟子被占住、以及更多的人要挨伤亡判定。
    界面上有「满编推荐」按钮。
    （注意：人数**不再**影响发现概率。）
13. **秘境还有弟子境界门槛，它等于「所属大区域的解锁境界」** ——
    需求 5 之后这条改过语义（以前是"小区域门槛松一级"）：
    东部群山的秘境**炼气期弟子就进得去**（包括富集区那处特产秘境），
    南疆要筑基、西漠要金丹、北境要元婴、中州要化神、无垠海要炼虚。
    **所以在大区内部，"弟子境界"不再是拦人的那一道** ——
    真正拦你的是**推荐战力**（战力比同时决定收益与伤亡）、**宗门品阶**（第 6 档起）与**冷却**。
    派太弱的队伍收益腰斩且死伤惨重。
14. **掌门游历**（开局就能用，**不需要开宗**）：
    掌门亲自出门，按境界开放 8 个目的地（山野荒村 90 秒 → 太初冰渊 1,800 秒）。
    带回灵石、资源、材料，并有机会带回**材料种子**；也有机会**发现新秘境**。
    ⚠️ **代价只有时间**：旧版那条"出游期间全局产量 −45%"已经**整条删除**
    （它只让玩家不敢出门，见 [BALANCE.md](BALANCE.md) 第九节）。
    掌门**不会陨落** —— 所以游历是「安全但慢」的材料来源。
    8 个目的地里有 5 个在东部群山，另外 3 个分别在南疆 / 西漠 / 北境的**资源富集区**。
    掌门在外时**还会继续遇到随机遭遇**（见上面「善恶值与随机遭遇」）。
15. **掌门独自探秘境**（🧘，需求 5）：**已经发现的**秘境卡片上多一个「掌门亲往」按钮。
    掌门自己去，**不占弟子、不会死人**，而且**更容易拿到稀有材料**（稀有材料权重 **×4**）——
    代价是**时长 ×1.4**、**总产出只有派队伍的 45%**、掉落条目只有 2 条，
    **而且同样进冷却**。
    ⚠️ 旧版这条路上还有"让洞府减产 45%"，**已经删除**（见常见问题「出门游历会掉产量吗？」）；
    所以现在的取舍是清清楚楚的"**慢一点、少拿一点，换稀有材料与不死人**"。
    想要星辰砂 / 太阴玄晶这类东西时，亲自跑一趟比派弟子划算；
    但它不是"免费的第二支队伍"，而是**拿家中产量换稀有材料**。
    两条要知道的边界：**掌门自己去不会发现新秘境**（开图只能靠弟子探索 / 普通探索 / 游历），
    而**「必掉」项对掌门同样保留** —— 秘境里 `guaranteed` 的那一条（比如特产秘境的特产）
    不管谁去都一定拿到，抽签只决定"额外拿到什么"。
    （这一条本轮修过一次：`resolveSoloRealm` 原先会把 `guaranteed` 忽略掉，
    见 [BALANCE.md](BALANCE.md) 第二十八节第 38 条。）
16. 秘境有 15% 概率直接掉落成品丹药；**化神期（第 5 档）起**的秘境还会掉**图纸**，
    越深的秘境概率越高（5% → 15%）。

### 🏯 宗门（修至**金丹期**开放）

17. **金丹期就能开宗立派**（需求 3 从化神期降下来的；**飞升仍然要化神期**，
    两个门槛已经拆成两个常量）。用灵石 **招收弟子**：宗门品阶越高，
    招到高资质弟子的概率越大（九品宗门有 30% 概率招到天灵根）。
    🆕 **弟子上限本轮整条换掉了（需求 1）**：
    `实际上限 = min(弟子居所床位, 品阶上限)`，其中**品阶上限是几何增长**的 ——
    **一品 100、二品 146、三品 213、四品 311、五品 453、六品 661、
    七品 965、八品 1,408、九品 2,048**（每升一品 ×1.459）。
    旧值是 `品阶 × 6`（九品也只有 **54** 人），
    所以这一次九品宗门的上限被放大了 **约 38 倍**。
    ⚠️ **两条线缺一不可**：床位数来自**弟子居所**（要自己盖，见第 21 条），
    而弟子居所**开宗之后才会出现** —— 所以"九品能收 2,048 人"是一句承诺，
    兑现它需要一路盖房子。
    📌 **但这两道门发挥作用的时期完全不同（这一点是刻意设计的）**：
    **早期卡你的是床位**（一品上限 100 人，而一座弟子舍只有 12 个床位，
    所以开宗后第一件事是盖房）；**中后期卡你的是品阶** ——
    弟子舍盖满 30 座就有 360 个床位，早就超过一品到四品的上限了，
    此后床位永远追得上，瓶颈变成"灵石够不够升品阶"（九品要 500 亿灵石）。
    实测终盘（跑满 30 天）是「弟子床位 **2,060** / 品阶上限 **2,048** / 存活 **1,663**」——
床位刚好比上限多一点，而**峰值人口 2,048 正好顶到九品上限**。
（更早那份只跑了 24.6 天的报告里这三个数是 1,420 / 1,408 / 1,040 —— 品阶每升一档，三个数一起跳。）
    **招收是固定价**（需求 3：「弟子招募在每个宗门品阶都是固定消耗，只是宗门等级越高越贵」）：
    **`60 × 品阶²` 灵石** —— 一品 **60**、三品 **540**、五品 **1,500**、九品 **4,860**。
    **同一个品阶里，招第 1 个和第 50 个一个价**；旧的 `× 1.1^已有人数`
    （第 40 位弟子要 **41 倍价**）已经整个删掉。
    ⚠️ **上一条有一个历史坑值得知道**：读档时弟子数量原来被硬夹在 **500**
    （旧时代的上限只有 54 人，500 是个防作弊数字）。上限抬到 2,048 之后，
    **第 501 名以后的弟子会在每次刷新页面时被静默丢掉** ——
    现在这个夹取改成跟着上限走（见 [BALANCE.md](BALANCE.md) 第 76 条坑）。
18. **宗门品阶直接决定能同时派几支探索队**：**起步就是 3 队**，
    之后每一品 +1 队，**七品起满 9 队**（`MIN_EXPEDITION_SLOTS = 3` +
    `MAX_EXPEDITION_SLOTS = 9`，公式是 `clamp(品阶 + 2, 3, 9)`）。
    ⚠️ **起点从 1 抬到 3 是更早一轮的修正**：一品宗门本来只有 6 个弟子名额，
    而队伍只有 1 支 —— 派不出去的弟子只能在门派里待着，
    而"弟子修行"这条线的一大来源是**探索归来才涨的心得**，
    于是"排不上队"约等于"进境越来越慢"（玩家原话：
    「宗门初始有 3 个派遣队伍，一个太少了，导致有的弟子一直无法去探索，修炼没有进境」）。
    （更早的写法是"每三品 +1 队"、九品也只有 4 队，所以升品阶对探索几乎没回报。）
    🆕 **注意本轮之后这条约束变紧了**：一品宗门现在能收 **100** 名弟子，
    而队伍还是 3 支 —— **所以"派谁出去"第一次成为一个真的选择**。
19. 弟子有自己的 **资质**（决定修炼速度**和**终身境界上限）、**境界**、**寿元**、**心得**。
    天灵根弟子 500 游戏年可至化神期；凡品灵根则止步化神。
    **弟子不得超越掌门境界** —— 想带出高手，自己得先突破。
    🆕 **弟子的大境界突破也要吃一颗对应境界丹（需求 9）**：
    修为攒满而仓库里没有那颗丹时，弟子**停在瓶颈**（**修为不丢**，
    进度刚好停在临界点），宗门记事里会写一句
    「XX 修为已满YY，只差一味ZZ便可破境」，弟子列表上也会打「**缺丹**」标签。
    ⚠️ **一个千人规模的宗门，每次有人破境都要一颗丹** ——
    所以"把炼丹线跑起来"从这一版起和"升境界"是同一件事。
    ⚠️ **寿元限制仍然生效**：炼气 **60 年**（≈ 8 小时）、筑基 150 年（≈ 20 小时）、
    金丹 400 年、元婴 900 年、化神 2,000 年、炼虚 4,500 年、合体 10,000 年、
    大乘 22,000 年、渡劫 50,000 年 —— 到寿元还没突破下一境界就**坐化**，
    所以要不断补招弟子。见常见问题「弟子为什么老是坐化？」。
    🆕 **弟子面板每批只渲染 50 行，多的人要点「显示更多（还有 N 人）」** ——
    上限抬到 2,048 之后，一次把上千行 DOM 铺出来会明显卡帧（需求 1）。
20. **仆役**从开局就能招收（住在**仆役居所**里），可以派去洒扫庭院（助益灵气）、
    入山伐木、凿石挖矿、采集灵草、淘洗灵石，每名给对应资源 **+4%** 产量。
    **招收花费固定 300 灵气**（需求 4；以前是 `80 × 1.2ⁿ` 的等比递增，
    第 10 个就要 495、第 30 个要 1.9 万）。
    🆕 **本轮需求 2 把"居所"拆成了两套**：**仆役居所**（茅屋 / 院落 / 洞天 / 仙府）
    只住仆役，**弟子居所**（弟子舍 / 精舍 / 静院 / 仙居）只住弟子，**互不占位**。
    以前两边抢同一批床位（"居所 − 仆人数"才是弟子容量），
    于是"多养仆人换产量"必然意味着"少收弟子换战力" —— 一道零和题。
    现在取舍变成"**资源先投哪一边**"。
    调整岗位请用「**调往…**」（下拉换岗，**总人数不变、不花灵气**）；
    🆕 面板底部还有一行「**批量调动**」：**源岗位 → 目标岗位 + 人数**，
    一次把 N 名仆人搬过去（还有「全部调走（N）」一键搬完）。
    「遣散」才会真正少一名，而且会二次确认、并提示以后重招要花多少灵气。
    （早先每行只有一个 `−` 按钮，点它其实是直接遣散 —— 想调岗却把人开除了，
    这是玩家报上来的 bug，见 [BALANCE.md](BALANCE.md) 第二十八节第 14 条。）

    🪨 **悟道石**（**弟子修炼 +6%/座**，8 座上限，**筑基期** + 1.2 万灵气 + 1,200 灵石）。

22. **宗门大阵（3 座，需求 1）**：**护山大阵 🛡（防御 +45%）→ 周天星斗大阵 ✨（+85%）

    通天塔涨心得，并且会**减少 2 次发现失败计数** ——
    也就是让你更快撞到硬保底（它**不提高概率**，概率只有宝盘能给）。

25. **大比（比武台）**：唯一由**你**决定开不开的宗门建筑。开启后**十年一度**自动开办，

### ⚗ 丹器

26. 用材料 **炼丹**：**28 种丹方**（本轮新增 💊 **保命丹**），
    每个品阶（一至九品）都有战斗型和辅助型。
    **丹方在面板上按品阶分组**（一至九品各一组，可以分别收起）——
    **你还没掌握的那些品阶默认收起**，标题上写着「尚未掌握」，
    所以九品配方不会把你现在能炼的那几档挤到看不见的地方。
    ⚠️ **境界丹现在是"门票"：大境界突破必须服一颗对应境界丹，没有丹连试都不能试**（需求 9）；其余丹药提供各种增益。
    ⚠️ **炼制不再是百分百成功**（需求 2）：**品阶越高、基础成功率越低** ——
    一品 **100%**、三品 88%、五品 70%、七品 50%、九品只有 **28%**；
    但**炼比自己低的品阶有加成**（每低一品 **+12%**），
    而且**相差三个品阶时必定成功**（这是需求明文写的硬规则，不是"算出来接近 100%"）。
    **失败照样扣材料**，并会在记事里写一条「炼制 X 失败 N 次（成功率 M%），材料已耗」。
    每张配方的按钮上方都会写明这一次的成功率，**不满 100% 时标红**。
    （面板上还写着「成功率 100%（高出 N 品，已至必成）」这种解释。）

    > 💊 **保命丹 vs 🛡 铁骨丹**（两颗都是"提高探索存活率"的丹药，但计价方式不同）：
    > **铁骨丹**（2 品）是**限时**的 —— 伤亡率 −25%、持续 10 分钟，适合挂机时覆盖一段时间；
    > **保命丹**（4 品）是**按次**的 —— 伤亡率 −40%、**不设时限**，
    > 在**下一次探索**结算时用掉。高等级秘境的基础伤亡已经到 **40%**，
    > 用"限时"覆盖它意味着得掐着表出门，所以高档次那一趟更适合磕一颗保命丹。
27. 配方由「基础资源 + 基础材料 + 稀有材料」构成。
    共 **16 种材料**（5 基础 + 8 稀有 + **3 进阶**，稀有度 1~6），
    **越高品阶的配方需要越多种稀有材料**（一品 0 种 → 九品至少 5 种）；
    而**四品以上的丹方还要额外吃 💧 灵液**（见第 31 条）——
    ⚠️ **本轮"灵液从三品挪到四品"是一次修 bug**：
    三品正好是"金丹 → 元婴"要用的那一档，而灵液要**筑基期**才能熬，
    放在三品就变成"想升三品先得有灵液、想要灵液先得升三品"的循环依赖
    （见常见问题「境界丹为什么炼不出来？」与 [BALANCE.md](BALANCE.md) 第 77 条坑）。
    渡劫丹要 120 个灵液、飞升丹要 400 个。
28. 用材料 **炼器**：**17 种器物**提供被动加成（本轮从 10 种加了 7 种），
    其中包括唯一的发现概率来源 **寻宝宝盘**（🧭，七品炼器，+4% 发现概率/面）
    与它的"不消耗版" **周天星图**（🌌，六品，+3.5% 且不会坏）。
    **生效件数 = min(持有数, 弟子数)**，所以造器物和收弟子要同步推进。
    **五品以上的器物还要额外吃 🥇 精金**（斩仙剑要 40 个、乾坤袋要 30 个）——
    严格说精金第一次出现是**五品的玄铁重剑（6 个）**，越往上越多。
    🎒 **其中 6 件是「可携带器物」，弟子探索时会自动带上，而且会用坏**（需求 2）：
    轻身符（速度 +20%，**12 次**）、采灵袋（产出 +20%，**10 次**）、
    引魂灯（伤亡 −18%，**8 次**）、御兽幡（战力 +30%，**6 次**）、
    虚空镜（产出 +35%，**5 次**）、长生法衣（伤亡 −30%，**4 次**）。
    每探索一次各消耗 1 次，**次数归零就从库存里消失，得重新炼**
    （记事里会写「携带的 X 已损毁，需重新炼制」）；
    卡片上显示「🎒 可携带 · 剩 N/M 次」，用光时接一句「（已损毁，需重炼）」。
    效果是**故意和永久器物重叠**的 —— 需求要的不是"更强的数值"，而是给弟子配装这件事本身。
    ⚠️ **注意：耐久越短的效果越强**，所以"该炼哪一件"永远是个取舍。
29. 提升 **炼丹术 / 炼器术品阶** 才能炼高阶物品。**丹房与炼器房现在是唯一建筑**
    （需求 2），升品**只看资源、不再要求盖几座房子** —— 旧的"要 N 座丹房才能升 N 品"
    整条规矩已经作废，丹炉阵 / 地火熔炉也不再提供"名额"，它们改成
    **炼丹 / 炼器成功率 +8%/座**（`max: 5` → 满配 +40%）。
    **升品还要先钻研「对应等级的技术」**（需求 6）：**2~4 品要 ⚗ 炼丹入门 / 🔨 炼器入门，
    5~6 品要 🫕 丹道精要 / 🌋 器道精要，7~9 品要 🌿 药王之道 / 🗼 通天营造** ——
    判定顺序是**先看技术、再看资源**，所以按钮上先告诉你的是"需先钻研「丹道精要」"，
    而不是"材料不足"。
    **唯一工坊可以在「建筑」的建筑卡上直接升级**：丹房 / 炼器房建好之后，
    卡片上会长出一行 `炼丹术 N 品 → N+1 品` + 花费 + 「晋升 N 品」按钮，
    玩家看着这座建筑就能推进它，不必再跑一趟丹器页（两处点的是同一个引擎函数）。
    ⚠️ **本轮升品花费整表重定过一次价（需求 9）**，因为丹药变成了硬门槛、
    炼丹术品阶也跟着变成主线必经之路：
    - **灵气部分统一压到"该品阶对应境界储存上限的约 25%"** ——
      旧价几乎吃满当前境界的上限（三品要 3e5，而筑基期上限正好只有 3.2e5），
      于是"想突破先得攒满仓库"，模拟里直接死锁（[BALANCE.md](BALANCE.md) 第 78 条坑）；
    - **💧 灵液 / 🥇 精金从三品挪到四品**（它们分别要筑基期 / 金丹期才能合成，
      放在三品就是循环依赖，第 77 条坑）；
    - **稀有材料整体下调**到"对应档次秘境 2~3 趟"的量级。
    **越到高级越吃稀有资源**：第 4 品起要 💧 灵液 / 🥇 精金，
    第 5 品起要星辰砂，第 6 品起要太阴玄晶，往后依次是龙血 / 九幽魂火 / 仙玉，
    第 9 品还要 🟣 混沌紫气或 🍑 鸿蒙道果。
    （炼丹术走"灵草 + 妖丹"那条线，炼器术走"灵矿 + 玄铁"那条线，
    但两条线吃的是同一批稀有材料 —— 所以中期要挑一条先走。）
    ⚠️ **实测里最容易卡住的一步是"炼丹 9 品"**：
    它要 **40 万灵草 + 仙玉 100 + 九幽魂火 200 + 600 灵液 + 3 鸿蒙道果**，
    而跑满 30 天之后**终盘「已用尽的材料：无」**，最紧的灵蚕丝也有 1.04 万 ——
真正的卡点变成了**灵气存量**（9 品升品要 4 兆，见 [BALANCE.md](BALANCE.md) 第二十六节读数 7）。
30. **自动合成**（面板在「**工坊**」页的 **合成 · 精炼** 里，可以收起）：
    **四条配方全都能自动合成**，而且控制方式是「**设一个目标存量**」——
    每条配方下面有一个「**自动合成到 N 个**」输入框（0 = 那条不管），
    上面是总开关与 **关闭 / 档 1 / 档 2 / 档 3**（0 / 0.05 / 0.2 / 0.8 批每秒）四档。
    系统会**按这个总速率，一批一批地补"缺口最大且还炼得动"的那条配方，补到目标就停手**。
    ⚠️ **速率是四条配方共用的**（不是每条一份）：否则四条各开最快档就是 3.2 批/秒，
    灵气会被瞬间抽干。
    ⚠️ **它现在是合成这件事唯一的入口**：「灵石合成」就是这块面板里的四条配方之一。
    详见 [BALANCE.md](BALANCE.md) 第十七节。

31. **进阶资源与合成（需求 4）**：在「**工坊**」页的 **合成 · 精炼** 面板里，
    把基础资源加工成三种**只能合成**的进阶资源
    （这块面板更早是从洞府搬到修行页、**本轮又从修行页搬到「工坊」页**）：

    | 配方 | 消耗 | 产出 | 门槛 |
    |---|---|---|---|
    | 💠 灵石合成 | **灵气 800 + 灵矿 100** | 灵石 **25** | 无 |
    | 💧 熬炼灵液 | 灵气 2 万 + 灵草 6,000 | 灵液 **1** | **筑基期** + 炼丹入门 |
    | 🥇 百炼精金 | 灵矿 9,000 + 灵石 2,500 | 精金 **1** | **金丹期** + 炼器入门 |
    | 🔯 刻制阵枢 | 灵木 8,000 + 灵石 2,000 | 阵枢 **1** | 元婴期 + 营造之术 |

    - 🆕 **灵石合成这一轮降价 6 倍多**（旧价是 5,000 灵气 + 500 灵矿）：
      玩家原话是「**灵石合成需求资源有点多了，前期没啥用，后期更没啥用，减少资源需求**」——
      前期的 5,000 灵气要攒半天，后期的灵石矿产量又把这条路挤成零头。
      现在 **800 + 100** 一批，开局点两下就有一批，中期则变成自动合成里的一条普通配方；
    - **门槛为什么要这么定**：灵液与精金分别是"炼丹 / 炼器升到 4 品"的材料，
      所以它们**必须能在用到它们之前拿到**，否则就是"想升 4 品先得有灵液、
      想要灵液先得升 4 品"（旧版把这一步放在三品上，正是如此 ——
      见常见问题「境界丹为什么炼不出来？」）。
      阵枢不参与任何突破链（它只进宗门大阵 / 空间戒指 / 感悟），所以留在元婴期；
    - **一次可以合 1 / 10 / 100 批**，而且是**立刻完成**的（不占时间、不排队）；
    - **每条配方都能设"自动合成到 N 个"**（见第 30 条），所以中期以后不必手点；
    - 它们**不能种、也不会从秘境掉落**（所以 16 种材料里只有 13 种有种子），
      商行虽然上架（灵液 3 个 9,000 灵石 / 精金 2 个 26,000 / 阵枢 2 个 22,000）
      但**只作应急**，自己合成便宜得多；
    - **出口**：五品以上的丹方吃 💧 灵液（渡劫丹要 900 个）、
      五品以上的器物吃 🥇 精金（斩仙剑要 40 个）、
      **三座宗门大阵**吃 🔯 阵枢（合计 5,850 个）、
      资源富集区的开启（18 处全开要 7,364 个）与感悟 / 空间戒指，外加商行。
    - ⚠️ **这一版实测终盘是「灵液 2,000 · 精金 1,000 · 阵枢 1,500」** ——
      三个数**正好停在模拟器 AI 设的自动合成目标上**（它给灵石设的是 4,000）。
      也就是说：**"终盘结余"从这一版起等于"你想囤多少"，而不是"产量吃剩下多少"**。
      想建三座大阵（5,850 个阵枢），**要把 `arrayCoreRefine` 的目标调到 6,000 以上**，
      而不是去改它的产率。

    详见 [BALANCE.md](BALANCE.md) 第二十五节。

    🏘 **精舍**（40 人，上限 30，要**营造之术**）、
    ⛩ **静院**（120 人，上限 25，要**洞天开辟**）、
    🏛 **仙居**（400 人，上限 20，要**洞天开辟**）。
    ⚠️ **它们全都要求"已开宗"（`requiresSect`）**，所以**开宗之前这一组在页面上根本不存在**
    （空组不渲染）；而原来那一组改名叫「**仆役居所**」，只住仆役。
    **这十组每一组都能单独折叠**（点组名就收起，组名右边显示这一组有几座建筑，
    所以收起来也知道里面有多少）；只显示**已经解锁且非空**的组。
    **唯一类建筑（丹房 / 炼器房 / 天工院 / 掌门大殿 / 比武台 / 三座大阵，共 8 座）
    建好之后不再显示"建造 1 / 排队"按钮**（需求 4）—— 整块按钮区直接不渲染，
    卡片上写「已建成 · 唯一」。
    ⚠️ **"不渲染"是刻意的**：灰按钮会让人以为是"资源不够，再攒攒就能建第二座"，
    而唯一建筑的第二座永远建不出来。
33. **建造队列**（🏗）：把想盖的东西排进队列，**资源一到就自动开工**，不用守着。
    - **初始 3 个名额**；建成下面的 **天工院** 再 **+1**；
      天工院还有 **3 次特殊升级**，每次 **+1** —— 满配 **7 个**；
    - 队列里第一项门槛没到或资源不够时会**原地等着，不会跳过**，
      面板上会直接写出它**缺什么**（缺哪几样材料 / 还差哪个门槛）；
    - 一次只开工一座（连建会让账目变得难预测）；
    - 「名额来源」条会显示 `初始 3 + 天工院 + 三级升级` 的点亮情况。
34. **天工院**（🏗，**金丹期**解锁、**唯一**、不需要钻研）：
    造好即 **建造队列名额 +1**。它的三级特殊升级是
    **扩建料场**（500 万灵气 · 20 万灵木 · 10 万灵石）、
    **增设工坊**（5 亿灵气 · 1,000 万灵木 · 500 万灵石 · 3,000 玄铁）、
    **请动仙匠**（500 亿灵气 · 10 亿灵木 · 5 亿灵石 · 20 万玄铁 · 500 太阴玄晶）。
    价格跨三个数量级，所以"开满 7 个名额"是一条贯穿中后期的小目标线。
    （它和开宗门槛现在是**同一档**：金丹期。）
35. **钻研技术**：**19 门**技术。一次只能钻研一项，需要先付材料再等 20~400 秒；
    **中途改钻研别的，已付材料不退**。
    面板在「**工坊**」页（需求 1 搬去修行页、**本轮需求 6 又搬到工坊页**），
    **已经掌握的技术会收进下面的「已完成（N）」折叠栏**，
    上面只留还没钻研的那几项 —— 十几项平铺时"下一个该钻研什么"反而难找（需求 7）。
    图纸那一块用的是同一套写法（已得的图纸收进「已完成」，未得的列出获取来源）。
36. **图纸**：**8 张**，钻研不出来，只能从秘境探索或商行获得
    （秘境那边**第 5 档起**才掉，越深概率越高）。
    它们只解锁**加成类**建筑（灵舟坊 / 雷池 / 星坛 / 万兽门 / 引魂灯阵 /
    照天镜 / 灵田阵 / 龙脉），拿不到只是慢一点，不会玩不下去。
37. 建筑的解锁条件共有**六层**：资源门槛（永久记录）+ 开宗 + 技术 + 图纸 +
    前置建筑 + 境界/宗门品阶。界面上会提前一级显示并标出还差什么。
    **只有 10 座资源设施、茅屋、储物袋、🛖 静室不需要钻研** —— 保证开局永远有路可走。
38. 存档管理、导出导入存档码、宗门记事（突破、陨落、秘境发现、随机遭遇、宗门事件的事件流）。
    🆕 **本轮需求 8 把「洞府」页缩到了只剩这一块**（存档 / 导出 / 导入 / 重开）——
    建造搬去了「建筑」、合成与钻研搬去了「工坊」。
    页签上写着「洞府」，因为"我这局玩到哪了"值得有自己的入口。

### 🌱 灵植（种植）

39. **种植**：**13 种材料有种子**（基础 5 + 稀有 8），另有 **3 种进阶资源没有种子**
    （灵液 / 精金 / 阵枢只能合成）。一块地种一颗，成熟时间按稀有度
    60 / 150 / 300 / 480 / 720 / 1,080 秒，收获 6 / 5 / 3 / 2 / 1 / 1 个。
    可以花**灵气**（便宜、推 90 秒）或**灵石**（贵、推 300 秒）**催熟**。
    收获是**手动**的，但有一键收获 —— 挂机 8 小时后自动收会把几十块地产出
    一次性塞进材料栏，玩家完全看不到发生了什么。
    地块由 灵植园（4/座）、药王圃（15/座）、灵田阵（40/座）提供，满配 410 块。
    ⚠️ **这一页现在只剩种植**（商行本轮独立成了页签，见上面 🏪）；
    页签上有个角标显示**有几块地熟了**。
    ⚠️ **实测里最容易紧的恰好是"基础材料"**：弟子人数涨起来之后，
    炼丹 / 炼器 / 升品的消耗跟着涨一个数量级，而种植供给只跟着地块数走 ——
    见常见问题「材料总是不够用？」

### 🏪 商行

40. **商行**：需要先钻研「商道」。每 **60 秒**刷新一次货架
    （需求原文写的是"每个游戏时间一个月"，但那样会变成 1 秒一刷 ——
    所以本作直接按真实秒定义，**和游戏日历无关**），
    上架 资源 / 基础材料 / 基础材料种子 / **进阶资源** / 图纸 五类。
    **刻意不卖稀有材料与稀有种子** —— 那是探索的价值所在。
    进阶资源（灵液 3 个 9,000 灵石 / 精金 2 个 26,000 / 阵枢 2 个 22,000）
    **只作应急**：自己合成便宜得多，商行的价值是"立刻到手、不看门槛"。
    商行最多 3 座（每座 +2 货位），「万宝楼」再加 4 货位/座（最多 3 座），满配 23 件。

### 飞升

修至**化神期**后可 **飞升**（注意开宗只要金丹期、飞升仍要化神期 —— 两个门槛是两个常量）：
重置一切（含宗门、弟子、技术、图纸、种子、商行、**善恶值**），
换取永久保留的 **道韵**（每点 +5% 全局产量）。
**已发现的秘境会跟着神魂一起带走** —— 需求说"发现后固定"，那就不该因为转世而丢掉。
（**纪年不会归零** —— 年份是从"修行时长"推出来的，所以第二世打开面板是"第 N 年"接着往下走。）

游戏每 10 秒自动存档。关掉网页也在涨 —— 离线收益按 50% 效率结算，最多累计 8 小时。
离线期间的探索、游历、独自探秘境、种植、钻研、商行刷新、**建造队列**、
**路上的随机遭遇**都会照常推进，
**季节与天象也会往前走**（离线跨季会直接落到那一季，天象只重掷一次 ——
这是为了不让离线结算变成"按四季做积分"，见 [BALANCE.md](BALANCE.md) 第二十二节）。

## 技术栈

| 用途 | 选择 | 为什么 |
|---|---|---|
| 构建 | Vite | 启动快、配置少 |
| 框架 | React 18 + TypeScript | 生态最大，类型能挡住大量低级错误 |
| 状态 | Zustand | 比 Redux 轻得多，适合每秒都在变的游戏状态 |
| 大数 | break_infinity.js | 见下方说明 |
| 样式 | 纯 CSS | 没有引入 UI 框架，方便随手改配色 |

### 为什么需要大数库

JS 原生 `number` 的有效数字只有 15~17 位，上限约 1.8e308。
放置游戏的数值会指数增长，用原生 `number` 会出现精度丢失甚至变成 `Infinity`。

`break_infinity.js` 能表示到 1e(9e15)，并且比 `decimal.js` 快得多。

**注意**：对超大数不要直接调 `toNumber()`（会溢出成 `Infinity`），
`src/game/decimal.ts` 里的 `fmt()` 已经处理好了，显示数值一律用它。

### 三个设计约束

**1. `game/` 里没有一行 DOM 或 React 代码。**
所以 `tools/simulate.ts` 才能在 Node 里直接跑真实游戏逻辑做数值模拟。
如果逻辑和界面混在一起，这是做不到的。

**2. 游戏用真随机，工具用固定种子 —— 边界写在代码里。**

| 场景 | 随机源 | 可复现？ |
|---|---|---|
| 浏览器里玩游戏 | `gameRandom`（即 `Math.random`） | **否**。由引擎从系统熵池播种，每次打开都不同，存档里不记录任何种子 |
| `pnpm smoke` 回归测试 | 固定种子伪随机 | 是，测试才能稳定复现 |
| `pnpm simulate` 数值模拟 | 固定种子伪随机 | **是**。同一份代码连跑两次逐行比对完全一致，只差"总耗时"那一行（见下面的 ⚠️） |

实现方式：所有涉及随机的游戏函数都接受一个可选的 `random` 参数，
默认值是 [`src/game/random.ts`](src/game/random.ts) 里的 `gameRandom`；
只有 `tools/` 会传入自己的种子随机数。冒烟测试里有一条断言在守着这条边界。

> ⚠️ **同一个坑踩过三次（现在都已修好）—— 它值得完整留着：
> `random` 的默认值就是 `Math.random`，漏传一处，整份模拟就不可复现。**
>
> | 第几次 | 漏传的位置 | 症状 |
> |---|---|---|
> | ① | `advanceLayer`（修行那一段） | 恶行种子的"天雷打断参悟"判定走 `Math.random`；同一份代码连跑两次，合体期能从 4 天 6 小时漂到 6 天 13 小时 |
> | ② | `startExpedition`（派队伍那一段） | 队伍 id 由 `Math.random` 生成，随机流被打断 |
> | ③ | `applyTickSim(g, dt)`（**时空穿梭**那一条，本轮新增的） | 每次穿梭把真随机注入随机流；主种子的合体期从 1 天 1 小时漂到 1 天 14 小时 |
>
> 三次的形状完全一样：**不报错、不崩、测试全绿、报告照常打印，只让整份模拟悄悄失效**；
> 而且三次的入口**都长在"新加的那条会推进时间的路径"上**。
> 现在**三处都已修好**（第三处补成 `applyTickSim(g, dt, random)`），连跑两次逐行一致 ✅。
>
> 教训是三条：**（1）`tools/` 里所有带 `random` 默认值的调用都必须显式传**；
> **（2）"同种子连跑两次对一下"是验证可复现性最便宜的办法**（三次都是这么抓到的）；
> **（3）只靠纪律不够 —— 应该把这条验证写成一条冒烟断言**，否则第四次还会来
> （见 [BALANCE.md](BALANCE.md) 第二十九节第 7 条）。
> 详见 [BALANCE.md](BALANCE.md) 第二十一节末尾与第二十八节第 46 条。

> 秘境发现也是随机的，但**硬保底计数（`discoveryFailures`，连续失败几次）会存档** ——
> 所以"真随机"不会变成"运气差就卡死"。

**3. 模块依赖是单向的，没有循环引用：**


## 部署到 GitHub Pages

### 1. 关键前提：改 `base`

GitHub Pages 的站点地址是 `https://<用户名>.github.io/<仓库名>/`，
是**子路径**而不是根路径。所以 [`vite.config.ts`](vite.config.ts) 里必须写：

```ts
export default defineConfig({
  base: '/gamefree/',   // ← 改成你的仓库名，两边斜杠都要
  ...
});
```

**这是 GitHub Pages 部署最常见的坑**：不改这里，页面会打开但一片空白，
控制台里全是 404。本地开发地址也会相应变成 `http://localhost:5173/gamefree/`。

> 例外：如果仓库名就叫 `<用户名>.github.io`，站点在根路径，那 `base` 要写成 `'/'`。

### 2. 推到 GitHub

```bash
git init
git add .
git commit -m "仙途：修仙放置游戏"
git branch -M main
git remote add origin https://github.com/<你的用户名>/<仓库名>.git
git push -u origin main
```

### 3. 打开 Pages

到仓库 **Settings → Pages → Source**，选择 **GitHub Actions**（不是 "Deploy from a branch"）。

### 4. 等自动部署

[`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) 会自动：
安装依赖 → 类型检查 → 冒烟测试 → 构建 → 发布。

推送到 `main` 后到 **Actions** 标签页看进度，
绿色对勾出现后访问 `https://<你的用户名>.github.io/<仓库名>/`。

### 5. 以后每次更新

```bash
git add .
git commit -m "调整数值"
git push
```

推上去就自动重新部署，不用做别的。

## 常见问题

**报 `ERR_PNPM_SPEC_NOT_SUPPORTED_BY_ANY_RESOLVER`，说 `#` 不被支持**
把命令后面的中文注释一起复制进终端了。`#` 在 cmd / PowerShell 里不是注释符，
请只复制命令本身。

**报 `ERR_PNPM_NO_IMPORTER_MANIFEST_FOUND`**
当前目录不是项目目录。先 `cd` 到有 `package.json` 的那个文件夹。

**页面打开是空白，控制台一堆 404**
`vite.config.ts` 的 `base` 没改成 `/<仓库名>/`。

**Actions 报错 `ERR_PNPM_IGNORED_BUILDS`**
pnpm 出于安全默认拦截依赖的安装脚本。本项目已在
[`pnpm-workspace.yaml`](pnpm-workspace.yaml) 里放行 esbuild，正常不会遇到；
如果你自己加了新依赖且它需要跑安装脚本，照那个格式加进去。

**资源栏为什么跑到左边去了？**
这是需求要求的：「界面上方的资源展示模块移动到左边，不要出现在其它模块的上方」。
所以页面骨架是「顶栏 → 页签 → **左侧固定资源栏** + 右侧内容区」，
资源栏用 `position: sticky` 跟着你滚动。
窄屏（≤1180px、≤900px）会把资源栏压窄到 150px / 124px，**但仍然在左边**；
只有手机宽度（≤620px）才允许它堆到内容上方。

这一轮资源栏本身还改了三处：**按类分成四组、每组各自展开收起**
（基础资源 / 基础材料 / **稀有材料（默认收起）** / 进阶材料，
选择记在浏览器里）；**每样资源多了一行"照这个速度多久填满"**
（已满 / 无产出 / 无上限 / 很久以后各有各的说法，不会硬塞一个 ∞）；
以及**原来压在资源栏最底下那条季节与纪年的常驻条已经删掉了** ——
纪年搬到了**页头右上角**。

**界面能不能再宽一点？**
已经加宽过了：内容区宽度是 **`min(1720px, 96vw)`** ——
也就是**随着窗口变宽**（1920 / 2560 的屏上几乎铺满），只在超宽屏留一个上限
（不然一行文字会长到眼睛累）；左右内边距 20px、底部 44px。
左侧资源栏固定 **196px**（≤1180px 的窗口自动压到 150px，≤620px 才允许堆到内容上方）。

顺带说明两处"看起来像装饰、其实是为了不突兀"的细节：

- **右上角那块纪年**（`第 N 年 · X季 · 今年 N%`）**没有自己的白底和边框** ——
  旧版它自带一层白底 + 实线边框，而页头本身是半透明的，于是右上角像贴了张便利贴。
  现在它只靠**左侧一条分隔线**说明"这块和左边那排读数是一家人"；
- **所有折叠组**（资源分组、建筑分类、丹方 / 器物品阶）都是同一个 `fold` 样式，
  收起来的组只在标题上留一个 `▸` 和数量，展开时才画出内容 —— 所以收起来不会留空块。

如果你想把默认宽度再调大/调小，改 `src/index.css` 里 `.app` 的 `max-width` 与
`.shell__side` 的 `flex` 就行，**不需要动任何组件**。

**钻研 / 合成 / 图纸在哪？**
都在「**修行**」页（需求 1 把它们从洞府搬过来了）——
**其中钻研与图纸排在「仆役」下面**（左栏从上到下是 打坐 → 仆役 → 钻研 + 图纸）：

**本地开发时存档存在哪**
浏览器的 localStorage。**键名仍是 `xiantu.save.v2`**，但内部的
`SAVE_VERSION` 已经是 **4** —— v1 / v2 / v3 存档都能平滑升级，导入时会自动补齐新字段。
旧存档里「靠材料解锁的秘境」会直接继承为**已发现**，不会让你丢掉走过的地图。
（v4 里新增的字段：**善恶值 / 待选遭遇 / 遭遇判定计时 / 遭遇倒计时**、
**掌门是在游历还是在独自探秘境**，以及
**感悟七条道的阶数（`en`）/ 正在感悟的道（`eg`）/ 空间戒指数（`sr`）/ 上次穿梭时间（`lj`）**；
更早一轮又加了一个 **`art`（各条配方的自动合成目标存量）** ——
它同样只认还存在的配方 id、并把数值夹到合法范围，老存档读进来是"一条目标都没有"，
也就是"自动合成开着也不会动手"，不会损坏也不会卡死。
🆕 **本轮删掉了一个旧字段**：`bp`（失败后累积的突破保底成功率）。
需求 9 取消了保底机制，所以**旧存档里的 `bp` 会被静默忽略** ——
不迁移、不折算（保底本来就是"失败攒出来的"，折成别的数等于凭空送进度）。）

**善恶值有什么用？怎么变善 / 变恶？**
它只影响两件事，但都很实在：

| 方向 | 后果 |
|---|---|
| **恶行**（善行值为负） | **突破更容易挨天雷**：恶行拉满时突破成功率 **−35%**，而且**参悟小境界也会被打断**（灵气照扣、落 2 分钟道伤）。好处是**恶行低到 −30 以下就解锁「抢劫」选项** —— 一次能拿大量材料甚至稀有材料 |
| **善行**（正数） | **探索产出加成**：善行拉满时 **秘境 / 普通探索 / 掌门独自探秘境** 的产出 **+30%**（游历不算） |

三档数值细节：

- 善恶值是一条 **−100 ~ +100** 的轴，开局是 0（中立），
  分**大善（≥60）/ 行善（≥20）/ 中立 / 作恶（≤−20）/ 大恶（≤−60）**五档；
- **它只能靠路上的遭遇选项改变** —— 打怪、探索、宗门都不会动它；
- **成功率有 15% 的下限**：作恶会更难，但不会变成"必须读档"。

想变善就选「出手相救」「施舍灵石」「指点迷津」这类；想变恶就选「驱赶」「摸走储物袋」
「下手抢夺」这类。面板上每个选项都写明了它会加/减多少善恶值。

**路上遇到的随机事件是什么？**
**任何时候都可能遇到人** —— 开宗前是在路上，**开宗之后山里的事与路上的事都会找上门来**
（需求 1 明确要求「随机事件开宗后也会遇到」）。
池子一共 **15 条**：

- **九条玩家事件**：🐫 行脚商队、🧎 落难的散修、🌿 采药童子、🧙 黑袍老者、⚔ 仙门巡使、
  🥣 乞儿、💊 游方郎中、🦊 受伤的灵兽、👨‍🌾 问路老农（开宗前只有这九条）；
- **六条宗门事件**（开宗后才进池子）：🏴 匪徒围攻山门、🐗 兽潮来袭、👹 魔修叩山、
  🎁 附庸来朝、💥 灵脉暴涨、⚖ 弟子争端。

- 大约每 **100 秒**判定一次（45% 概率遇到），遇到后会**停在面板上等你选**；
- **每条在屏幕上只停 30 秒**：玩家事件与普通宗门事件到点**自动消失、没有影响**；
  而**上面那三条进攻类**到点会**照常结算** —— 卡片上会直接写出
  「进攻宗门 —— 不处理就会照常结算」以及**宗门防御 % / 预期受伤弟子 N 人**；
- **每个遭遇都至少有一个"什么都不用付"的选项**（比如灵兽那条的「绕开」）——
  所以你不会因为"灵气不够、又不够恶"被卡住；
- 选项的收益 / 代价 / **成功率**都直接写在按钮上，不能选时还会写清原因；
- 左侧资源栏的善恶值那一行，**有待选遭遇时会显示一个「遇」字角标**。

**宗门被进攻了怎么办？**
先看那句预警：「进攻宗门 —— 不处理就会照常结算」。你有三条路，按代价从小到大：

| 做法 | 结果 |
|---|---|
| **在 30 秒内选一个选项** | 按选项结算（有的花灵石、有的花灵气，有的要掌门亲自迎敌挨点道伤） |
| **放着不管** | **照常结算**：按"强度 × (1 + 掌门境界 × 8%) × (1 − 宗门防御)"算烈度，扣资源、伤弟子 |
| **提前建宗门大阵** | **一劳永逸**：🛡 护山大阵 +45% → ✨ 周天星斗大阵 +85% → 🌀 混元无极阵 +130%，**累加**。三座叠满 2.60 ≥ 1，烈度直接归零 —— 来犯者连山门都靠近不了 |

三条要注意的：

1. **受伤的弟子是按境界从低到高挑的**（强者顶在前面），而且**只是进道伤、不会陨落** ——
   随机事件不杀人；
2. **一次最多打掉每种资源的 12%、最多打伤 35% 的弟子**（有上限，不会把家底清零）；
3. **掌门境界越高，事件强度越大**（每高一个境界 +8%）——
   所以"开宗初期建一座护山大阵"和"大乘期才建"的价值不一样，越早越省心。

成本那边要记住：**三座大阵要的是 🔯 阵枢**（50 / 800 / 5,000 个，合计 **5,850**），
那是只能自己合成的进阶资源（见下面「进阶资源怎么来？」）。
实测 30 天终盘阵枢**只有 1,500**（它停在自动合成的目标上）——
也就是说**按当前那组目标，三座大阵是攒不齐的**；
"没建"只是因为你还没把它排进队列（模拟器里的 AI 就是这样：它优先盖产量建筑）。
详见 [BALANCE.md](BALANCE.md) 第二十三节与第十四节。

**掌门独自去秘境划算吗？**
看你要什么：

| | 🌌 派弟子队伍 | 🧘 掌门亲往 |
|---|---|---|
| 时长 | 基准 | **×1.4（更慢）** |
| 总产出 | 100% | **45%**（一个人背不动） |
| 稀有材料权重 | ×1 | **×4** |
| 掉落条目 | 3~6 条 | 固定 **2 条** |
| **必掉项**（特产秘境的特产等） | 保留 | **保留**（抽签只决定"额外拿到什么"） |
| 弟子心得 / 丹药 / 种子 / 图纸 | 会掉 | **都不掉** |
| 会死人吗 | 会（按战力比） | **不会** |
| 占弟子吗 | 占一支队伍 | **不占** |
| 洞府产量 | 不受影响 | **不受影响**（旧版的出门减产已删除） |
| 冷却 | 写 | 写（同一张表） |

**结论：想要稀有材料（星辰砂 / 太阴玄晶 / 九幽魂火）时，亲自跑一趟比派弟子划算；
但它不是"免费的第二支队伍"，而是拿家中产量换稀有材料。**
还有一条要知道：独自前往**不会发现新秘境**（开图只能靠弟子探索 / 普通探索 / 游历）。

**掌门亲往和派队伍有什么区别？**
上一条说的是掌门独自去**已经发现的秘境**；这一条说的是**普通探索**
（在还没发现秘境的小区域"去附近转转"）。两者的取舍不一样：

| | 🔍 派弟子普通探索 | 🧘 掌门亲往（普通探索） |
|---|---|---|
| 前置 | 已开宗 + 有空闲弟子 + 有一支空队伍 | **只要这一带能做普通探索**（**开宗前就能出门**） |
| 时长 | 基准 | **×1.25** |
| 产出 | 基础材料 1~2 种（必定）+ **30%** 稀有 | 基础侧**减半**；稀有侧也是 **30%**（`SOLO_SURVEY_RARE_CHANCE`，与派队伍同概率）|
| 伤亡 | 无 | **无** |
| 占弟子 | 1~4 名 | **不占** |
| 占队伍名额 | **占一支** | **不占** |
| 洞府产量 | 不受影响 | **不受影响**（旧版的出门减产已删除） |
| 心得 / 种子 / 图纸 | 心得有（秘境的一半），其余不掉 | **都不掉** |

**一句话**：派队伍负责产量，掌门负责探路 —— **两个人的稀有概率一样（都是 30%）**，
掌门赢在"不折损弟子、不占名额、开宗前就能出门"。
所以开宗前、弟子都在忙、或者只是想"顺手把新区域开出来"的时候，掌门自己去最划算；
想靠它刷产量不现实（基础材料只有一半，还压着洞府产量）。

> ⚠️ 这条口径是**收尾修复**改过来的：最初 `resolveSoloSurvey` 写的是裸的
> `weightedDraw(rare, 1, random)`，而它是"不放回抽 1 项"，**稀有池非空时必定返回 1 条** ——
> 于是掌门亲往变成了"100% 带一样稀有回来"，比派队伍还高。
> 现在先掷一次 30% 再抽，两边对齐（见 [BALANCE.md](BALANCE.md) 第六节与第二十八节第 60 条）。

⚠️ 两条容易混淆的边界：**掌门亲自普通探索不占队伍名额**
（所以哪怕队伍名额全满了也照样能出门）；
而**掌门亲自探秘境**是另一条路（上一条那个表，×1.4 时长 / 45% 产出 / 稀有 ×4 / 占冷却）。

**弟子为什么老是坐化？**
因为**寿元限制本轮重新生效了**（需求 2：「弟子增加寿命限制，等级可以增加寿元，
但是到达寿元限制仍然没有突破下一境界则会坐化」）。
一年 = 现实 8 分钟，所以寿元换算成真实时间是：

| 境界 | 寿元（游戏年） | 换成真实时间 | 修炼到下一境界要几年 |
|---|---|---|---|
| 炼气期 | **60** | **8 小时** ⚠️ | 50 |
| 筑基期 | **150** | 20 小时 | 80 |
| 金丹期 | **400** | 2.2 天 | 120 |
| 元婴期 | **900** | 5 天 | 250 |
| 化神期 | **2,000** | 11 天 | 400 |
| 炼虚期 | **4,500** | 25 天 | 700 |
| 合体期 | **10,000** | 56 天 | 1,200 |
| 大乘期 | **22,000** | 122 天 | 2,000 |
| 渡劫期 | **50,000** | 278 天 | 5,000 |

三条要点：

1. **每一档的寿元都比"本境界修炼所需年数"长，但只长 1.2 ~ 3.3 倍** ——
   所以"能修满再突破"始终成立，可**低资质弟子（修炼速度 0.25 ~ 0.45）
   如果建筑 / 大比 / 心得没跟上，就会卡死在当前境界**（比如凡品灵根单独修炼气期要 200 年，
   而寿元只有 60 年）。
2. **炼气期是最紧的一档**：天灵根（速度 1.0）修到筑基要 50 年，寿元只有 60 年 ——
   只留 10 年余量。所以**开局要尽快把弟子送出去探索攒心得、把功法殿 / 大比开起来**，
   否则招进来的弟子会一批批坐化。
3. 🆕 **本轮实测的人口结构与更早完全不同**：终盘是
   **渡劫 3 · 大乘 264 · 合体 507 · 炼虚 233 · 化神 120 · 元婴 109 · 炼气 427（共 1,663 人）** ——
   一座**中间最粗的纺锤形**（最粗的是合体那一档）。原因是**弟子上限被抬到了 2,048**，
   招收变成一件"随便做"的事（一品 60 灵石），所以底层永远有人在补充。
   ⚠️ **累计招收 312,403 人 / 存活 1,663 人**：也就是说"换人"是这一版的常态
   （**换掉了 188 倍**），而不是意外。
   📌 **顺带一个"窗口长度"的对照**：只跑 24.6 天时，这张图是
   **下宽上窄的金字塔**（最粗的是元婴 568 人，共 1,040 人）——
   多跑 5 天半之后那批人上行到了合体。**同一局游戏、不同的观测点，形状完全不同。**
4. ⚠️ **秘境伤亡是另一条独立的人口出口**：
   九档秘境的基础伤亡已经到 **40%**（一档 2% → 九档 40%，
   同一小区域内越靠后越高，最深处 42%）。所以"弟子突然少了一批"未必是坐化，
   也可能是队伍折在了深处的秘境里（记事里会写「XX一行折损：… 陨落」）。

**弟子卡在瓶颈了？（修为满了但不突破）**
🆕 **本轮最常见的原因变成了"仓库里没有那颗境界丹"** —— 需求 9 起，
**弟子的大境界突破也要消耗一颗对应境界丹**。

怎么认出来：弟子那一行会写「**修为已满XX期，缺 ZZ丹 ×1**」，
并打一个红色的「**缺丹**」标签；宗门记事里也会写一条
「XX 修为已满YY，只差一味ZZ便可破境」。

**修为不会丢** —— 它会**停在临界点上等着**，所以你不必担心"白攒了"。
缺丹时弟子**不会继续往上冲**，会一直卡在那里直到你把丹炼出来。

怎么解决（按性价比排序）：
1. **去「丹器」页炼那颗丹** —— 先看炼丹术品阶够不够（规则是 `丹的品阶 = 境界下标 + 1`），
   再看材料；
2. **派队伍去秘境**，成品丹药有概率直接掉（`TIER_PILLS`）；
3. **掌门亲往秘境**也可能带回来（稀有材料权重 ×4）。

⚠️ **一个千人规模的宗门，每次有人破境都要一颗丹** ——
所以"把炼丹线跑起来"从这一版起和"升境界"是**同一件事**。
实测里元婴期堆了 **568 人**，全都在等四品的化神丹（需要炼丹术 4 品 + 灵液）。

**弟子在派遣期间修行更快吗？**
🆕 **是，快 50%**（需求 10：「弟子应当可以在派遣（包括探索）的过程中，
获取经验值，加快修炼速度」）。

- 弟子只要状态是"探索中"，修行速度就 **×1.5**；
- 列表上会打一个 **「探索中 · 历练 +50%」** 的标签；
- 弟子面板上写的"还要几年入XX期"**已经把这 50% 算进去了**
  （界面和实际涨修为用的是同一个函数）；
- ⚠️ 它**不与建筑加成互相放大** —— 它是乘在加成池外面的一个独立系数；
- 📌 **它与「心得」是两回事，可以叠加**：这是"在外期间的过程收益"（每秒都在涨），
  心得是"归来时的里程碑收益"（永久提高倍率）。
  所以"队伍一直挂在外面"确实更划算 —— 但秘境有伤亡代价，别为了这 50% 去打不该打的仗。

**掌门出门了，怎么看还有多久回来？**
🆕 **「探索」页顶部的「进行中」那一块会画一根进度条**，三种出行方式都会显示：

| 出行方式 | 文案 |
|---|---|
| 掌门游历 | `🧭 掌门游历 {目的地}` |
| 掌门独自探秘境 | `🧘 掌门独自探索 {秘境}` |
| 掌门亲自普通探索 | `🧘 掌门亲自查探 {小区域}` |

⚠️ **本轮修掉的一个 bug**：进度条原来只在"游历"和"独自探秘境"两种情况下渲染，
**第三种（亲自普通探索）整块被跳过** —— 所以会出现"有时没有进度条"。
现在三种都有，中止按钮的文案也跟着分「中止游历 / 中止探索」

**界面为什么变成黑白了？**
🆕 因为需求 3 要求「UI 改为黑白风」。做法是**把色相整个抽掉，只留墨与纸**：
底是纸（`#f3f3f3`）、字是墨（`#171717`），强调色也从朱红换成了**焦墨**。

**唯一保留的颜色是警示红**（资源不足 / 伤亡 / 危险 / 锁定 / 满仓那一类）——
需求要的是"黑白风"，不是"绝对不能有颜色"，而这些状态必须能从一屏灰里跳出来。

顺带一提：**资质与稀有度的颜色也一起改了**（它们写在代码里、不是 CSS，很容易漏）——
现在六档资质与六档稀有度都是灰阶，靠**明度**分档：**越好的越黑**
（天灵根 `#141414`、凡品灵根 `#a9a9a9`；道品 `#151515`、凡品 `#b3b3b3`）。

**材料总是不够用？**
> ⚠️ **先说结论的适用范围**：这一条在"只跑了 24.6 天"的那份报告里看起来像结构性缺口
> （最紧的灵蚕丝只剩 **19**），**但把窗口跑满 30 天之后它自己就好了** ——
> 灵蚕丝 **1.04 万**、终盘「已用尽的材料：无」、16 种材料全部有存量。
> 所以下面这套分析**只在"你玩到人口暴涨、而种植还没跟上"的那一段时间里成立**：
> 它描述的是**暂态**，不是永久缺口。
> 📌 **这也是本项目第一次栽在"观测窗口"上**，教训记在
> [BALANCE.md](BALANCE.md) 第二十六节读数 7 与第二十九节。

🆕 **如果你正处在那一段**（弟子数在几小时里涨到四位数、而地块还只有十几块），
当时实测里最紧的是 **灵蚕丝**，
而它同时是"炼丹 9 品 / 炼器 9 品"的升品材料。

根因不是"掉率低"，而是**供需两头涨得不一样快**：
- **需求侧**：弟子上限从 54 涨到 **2,048**（实测存活 **1,663 人**、峰值 2,048），
  于是炼丹 / 炼器 / 升品的消耗跟着涨了**一个数量级**（每次破境还要一颗丹）；
- **供给侧**：基础材料主要靠"种植 + 秘境基础掉落"，
  而种植只跟着**地块数**走（当时只用了 11/48 块地；跑满 30 天之后是 18/48，
  而人口增长在后段放缓，两条线就追上了）。

现在能做的几件事：
1. **把地块开满**（灵植园 4/座、药王圃 15/座、灵田阵 40/座，满配 410 块）
   并**多派"采集灵草"的仆役**；
2. **把「工坊 → 合成 · 精炼」的自动合成目标调高**（默认目标只在几百到一千的量级），
   让它持续把基础材料转成你缺的那一样；
3. 注意**仆役床位没有上限**（茅屋 / 院落 / 洞天都能一直盖），
   而每个仆役给对应资源 **+4%** —— 中后期"多盖房多收仆人"是最直接的产能手段。

⚠️ 顺带解释一个历史问题：**上一版弟子"好像不会老死"** ——
那是因为纪年从"一年 12 秒"变成"一年 8 分钟"之后，
以游戏年计价的 `lifespan`（炼气 300 年）真实含义跟着变成 40 小时。
本轮**按新日历把寿元重标定了一遍**（300 → 60 等），这条线才回来。
**教训：改日历必须回头重标定所有以"游戏年"计价的数值**

**弟子怎么突然死了这么多？**
先看记事，它会告诉你死因 —— **弟子有两条独立的出口**：

| 出口 | 记事里的写法 | 怎么减少 |
|---|---|---|
| **寿元耗尽坐化** | 「XY 寿元耗尽，坐化」 | 招资质更高的（修炼更快）、把**功法殿 / 讲道堂 / 大比 / 心得**堆起来（修行倍率不够时，凡品灵根修不到下一境就老死了） |
| **秘境伤亡** | 「XX一行折损：… 陨落」 | 提高**战力比**（派更强的队伍 / 带更多人或更多器物）、**降低秘境档次**、吃 🛡 **铁骨丹**（限时 −25%）或 💊 **保命丹**（按次 −40%）、建 🏮 **引魂灯阵**（伤亡 −8%/座）与带 🏮 **引魂灯 / 🥋 长生法衣**（可携带，−18% / −30%）|

三条要点：

1. **伤亡是正反馈**：多死几个 → 队伍凑不满 → 战力比下降 → 伤亡率进一步升高 →
   死得更多。所以看到伤亡苗头时**先把队伍撤回来打低一档的秘境**，
   别硬着头皮派残队（模拟器就因为把残队往深处送而两次把宗门清空，
   见 [BALANCE.md](BALANCE.md) 第二十八节第 18、19 条）。
2. **战力比同时决定收益与伤亡**（`伤亡率 = 基础伤亡 ÷ 战力比 × (1 − 减免)`）——
   所以"派太弱的队伍"是双输：既赔产出又赔人。
3. **本轮"高等级秘境死亡率更高"是明文需求**：一档 2% → **九档 40%**。
   深处的秘境就该是"要用器物和丹药兜着才敢去"的地方 ——
   这也是本轮新增那 6 件可携带器物与保命丹的原因。

**元婴期**解锁，七条道、每条 **90 阶**（9 个大阶段 × 10 个小阶段）。
面板在「**感悟**」页（它现在是一个**独立页签**，紧挨着「洞府」）。

| 道 | 加成 | 值不值得修 |

| ⚔🌳💧🔥⛰ **五行五条** | 各自绑一种基础材料，**每阶 +1.5%、满阶 +135%** | **非常值**：材料是中后期一切配方与建筑的原料，而且它是**独立乘区** —— 连冬天灵草 −35% 都盖不住它 |

1. **一次只能修一条道**，中途取消不退资源，所以要修就挑"当前最缺的那种材料"那条；
2. **花费横跨四种资源 + 进阶资源**：一阶 45 秒起（`45 × 1.045^阶`，第 90 阶约 38 分钟），

   所以修感悟和建宗门大阵会抢阵枢，**自己排个优先级**；
3. 五条五行**齐头并进最划算**（因为材料是并用的），

   再上一版 **82/…/81/81** → 上一版 **88×7（七条齐平）** →

**时空穿梭有什么代价？**
它是「把这段时间里的一切一次性结算」——产出、钻研、灵植、秘境冷却、弟子修炼
全都往前走一大段，看起来是白送的。**但代价有三条**：

1. ⚠️ **弟子会真的老去**：穿梭的年数照样加在弟子年龄上，
   **寿元不够的会当场坐化**（记事里会写"弟子 X → Y 人（寿元不足者已坐化）"）。
   所以跳时间之前先看一眼弟子年龄 —— 尤其是刚招进来的炼气弟子（寿元只有 60 年）；
2. **产出会被储存上限吃掉**：穿梭期间产出的资源顶到上限就白白溢出，
   所以"跳之前先扩仓库"是真的有用；
3. **冷却 5 游戏年（40 分钟）** —— 一次跳 22 年（34 阶时）的话，
   等于用 40 分钟换 22 年；**修到满阶就是 40 分钟换 50 年**，这也是它最强的用法。

⚠️ **一句实话**：按当前数值，**满阶能跳 50 年、冷却只有 5 年 = 10 倍的时间倍率**
（本轮实测修到 81 阶 = 一次 **46 年** ≈ **9.2×**）。
**这是设计使然**（需求原文就是「每隔五年可以进行一次时空穿梭，穿梭时间最大为 50 年」），
相当于**把时间按 10 倍速过一遍，代价是弟子跟着老 50 年**。
它**不改产出上限、只改时间**，所以从产量曲线上完全看不出来，
却能把"炼虚 → 合体"这种长阶段直接压短（实测从 6 天 10 小时压到 **23 小时 32 分**）。
⚠️ 本轮还有一个反向的观察：**这一版把秘境单趟时长拉长了 46.7×、冷却拉长到 40×，
合体期中位却只被推后了 1 小时** —— 也就是说**按真实秒计的改动都会被穿梭稀释**，
真要收住节奏，动的应该是穿梭本身的冷却。
是否太强留待观察，讨论写在 [BALANCE.md](BALANCE.md) 第二十九节第 3 条。

**合成栏能自动合吗？**
能，而且**四条配方都能**（本轮之前只有灵石这一条能自动合）。
位置在「**修行**」页的 **合成 · 精炼** 面板：

| 控件 | 在哪 | 干什么 |
|---|---|---|
| **自动合成** 总开关 + 四档 | 面板**顶部** | 关闭 / 档 1 / 档 2 / 档 3 = **0 / 0.05 / 0.2 / 0.8 批每秒** |
| 「**自动合成到 N 个**」输入框 | **每条配方**的卡片底部 | 你要攒到多少；**填 0 = 那条不管** |

规则三条：

1. 系统按**总速率**一批一批地合成，每一批都挑**"缺口最大、而且材料够"的那条配方**去补；
2. **补到目标就停手**（不会一直合下去，也不会把灵气抽干）；
3. ⚠️ **速率是四条配方共用的**，不是每条一份 —— 否则四条都开最快档就是 3.2 批/秒，
   灵气瞬间见底。**这就是"给一个总闸门 + 每条设目标"而不是"每条各自调速"的原因。**

⚠️ **两个容易踩的点**：

- **没设目标的配方不会被自动合成**（包括灵石那条）—— 所以"开了自动合成却没动静"
  十有八九是目标还是 0；
- **终盘结余 = 你设的目标**。模拟器 30 天终盘是「灵液 2,000 · 精金 1,000 · 阵枢 1,500」，
  就是因为 AI 给自己设的目标正好是这几个数（它给灵石设的是 4,000）。
  所以**想让某样东西更多，改的是目标，不是产率** ——
  比如三座宗门大阵要 5,850 个阵枢，就得把「刻制阵枢」的目标调到 6,000 以上。

详见 [BALANCE.md](BALANCE.md) 第十七节（含"为什么原料看存量、产出看余量"那条坑）。

**炼制为什么会失败？**
因为需求 2 明文要求「炼制对应等级的丹药或者器物并不能百分百成功，有概率失败」。
规则一共四条：

| 规则 | 数值 |
|---|---|
| **品阶越高，基础成功率越低** | 一品 **100%** · 二品 95% · 三品 88% · 四品 80% · 五品 70% · 六品 60% · 七品 50% · 八品 39% · **九品 28%** |
| **炼比自己低的品阶有加成** | 每低一品 **+12%** |
| **相差三个品阶时必定成功** | 直接 100%（**硬规则**，不是"算出来刚好接近"） |
| 丹炉阵 / 地火熔炉再加成 | 各 **+8%/座**（`max: 5` → 满配 **+40%**，加算） |

- **失败照样扣材料** —— 那是失败的代价。一次炼多份时是**逐份独立掷骰**，
  所以炼 10 份九品丹大概率只成 2~3 份；
- 失败会在记事里写一条「炼制 X 失败 N 次（成功率 M%），材料已耗」；
- 每张配方的按钮上方都会写明这一次的成功率，**不满 100% 时标红**，
  差三品时会写「成功率 100%（高出 N 品，已至必成）」；
- 💡 **降低失败的两条路**：要么**把品阶堆高**（差三品必成），
  要么**盖丹炉阵 / 地火熔炉**（每座 +8%，最高 +40%）——
  三座炉子就能把「四品炼丹术炼四品丹」从 80% 抬到 **100%**，
  满配能把九品丹从 28% 抬到 **68%**。所以"先修哪条线、先盖几座炉子"都是真决策。

> 💡 **顺带说一个已经被冒烟测试钉住的细节**：丹炉阵 / 地火熔炉那 +8% 曾经**只写在描述里、
> 代码里没有真的赋值**（建筑白建了），后来补上并加了两条结构性断言 + 一条行为断言。
> 这类"描述声称的效果必须真的带来数值变化"的检查见
> [BALANCE.md](BALANCE.md) 第三节、第十五节与第二十八节第 51 条。

**丹房怎么升级？**
两个地方都能升，点的是同一套逻辑：

1. **在「建筑」页的建筑卡上直接升**（推荐）：丹房 / 炼器房建好之后，
   卡片上会多出一行 `炼丹术 N 品 → N+1 品` + 花费 + 「**晋升 N 品**」按钮 ——
   玩家看着这座建筑就能推进它，不必来回切页；
2. **在「丹器」页升**：和炼丹药、炼器物放在一起。

两条要记住的规则：

- **升品需要先钻研「对应等级的技术」**（需求 6）：
  **2~4 品**要 ⚗ **炼丹入门 / 🔨 炼器入门**，
  **5~6 品**要 🫕 **丹道精要 / 🌋 器道精要**，
  **7~9 品**要 🌿 **药王之道 / 🗼 通天营造**。
  判定顺序是**先看技术、再看资源** —— 所以按钮上先告诉你的是
  「需先钻研「丹道精要」」，而不是"材料不足"（技术才是你该去做的下一件事）；
- **升品只看资源与那门技术，不再要求"盖几座丹房"** ——
  丹房与炼器房都是**唯一建筑**（各 1 座），旧的"要 N 座丹房才能升 N 品"整条作废。
  🆕 **本轮这两张花费表整表重定过一次价（需求 9）**，因为丹药变成了硬门槛、
  炼丹术品阶跟着变成主线必经之路：
  - **灵气部分统一压到"该品阶对应境界储存上限的约 25%"** ✓
    （例如升 3 品要 **8 万灵气**，而筑基期的储存上限是 **32 万**）——
    旧价几乎吃满当前境界的上限（三品要 30 万），于是"想突破先得攒满仓库"，
    模拟里直接死锁；**冒烟测试有一条断言守着"升品花费 ≤ 该境界储存上限的一半"**；
  - **💧 灵液 / 🥇 精金从三品挪到四品**：它们分别要筑基期 / 金丹期才能合成，
    而三品正是"金丹 → 元婴"要用的那一档 —— 放在三品就是循环依赖（见下一条）；
  - **稀有材料整体下调**到"对应档次秘境 2~3 趟"的量级。
  现在是：**第 4 品起**要 💧 灵液 / 🥇 精金，**第 5 品起**要星辰砂，
  第 6 品起要太阴玄晶，第 7~8 品要龙血 / 九幽魂火，第 9 品要仙玉 **外加**：
  **炼丹术**要 🍑 **鸿蒙道果 3 个**、**炼器术**要 🟣 **混沌紫气 20 个**
  （这是两条线在最高一档才分岔的地方）。

**境界丹为什么炼不出来？**
先看它卡在哪一环 —— **境界丹的整条前置链，都会被"它服务的那个境界"上下的东西卡住**，
所以历史上真的出现过"想突破金丹得先到金丹"这种死循环。这一条链现在是逐环检查过的：

| 环 | 例子（**元婴 → 化神**这一跳，也就是**第一次要用到灵液**的那一跳） |
|---|---|
| 那颗丹本身 | **化神丹是 4 品丹**，要求炼丹术 ≥ 4 品（而且要先钻研「炼丹入门」） |
| 升品要的材料 | 炼丹术升到 4 品要 **10 份 💧 灵液** |
| 材料从哪来 | 灵液**只能合成**（灵气 2 万 + 灵草 6,000），门槛是 **筑基期 + 炼丹入门** ✅ |

⚠️ **关键在最后一行**：灵液的合成门槛**必须早于它服务的那个境界** ——
它要**筑基期**，而第一次用到它是**元婴期**，中间隔了两个大境界，所以这条链是安全的。
而**本轮修掉的正是"它曾经挂在三品上"**那个版本：三品是"金丹 → 元婴"要用的那一档，
于是变成"想升三品先得有灵液、想要灵液先得升三品"。
（历史上还出现过另一种：灵液要**金丹期**才能熬，也就是"突破到金丹之后才能拿到
突破到金丹的材料" —— 那颗丹你永远炼不出来，而游戏**不报错、不崩、界面照常**，
只是进度静默地卡住。）

如果你现在炼不了某颗境界丹，按顺序查四件事：

1. **炼丹品阶够不够**（那颗丹是几品，就要几品炼丹术；卡片上写着「需 N 品炼丹术」）；
   品阶规则是 **`丹的品阶 = 境界下标 + 1`** ——
   筑基丹一品、凝金丹二品、化婴丹三品、化神丹四品、炼虚丹五品、
   合体丹六品、大乘丹七品、渡劫丹八品、飞升丹九品；
2. **升品的技术钻研了没有**（2~4 品要炼丹入门、5~6 品要丹道精要、7~9 品要药王之道）；
3. **升品/炼制的材料够不够**（第 4 品起要灵液，第 5 品起要星辰砂……材料清单直接印在按钮上方）；
4. **境界够不够**（灵液要筑基期、精金要金丹期、阵枢要元婴期）。

> 🆕 **本轮之后最常见的"炼不出来"其实是"料不够"而不是"顺序错"**：
> 跑满 30 天之后主种子的卡点是「**炼丹 9 品 材料不足**」，但同一行还写着「**卡点材料：无**」——
> 也就是说**材料都够了，卡的是灵气**（9 品要 4 兆，手上有 1.85 兆；
> 而渡劫期的灵气上限是 144.84 兆，所以这不是死锁，只是还没攒够）。
> 弟子人数涨起来之后，炼丹 / 炼器 / 升品的消耗跟着涨一个数量级，
> 所以中后期真正该盯的是**基础材料的产能**（多开地块、多派采药队），
> 见常见问题「材料总是不够用？」。
>
> 这一族问题（"某个东西的前置比它自己更晚"）**不止境界丹一处** ——
> 某一轮还查出**秘境要求了一个该境界根本达不到的宗门品阶**，一共 **67 处**；
> 另一轮又用同一套判据扫出**8 座建筑**有同样的毛病（已一并夹过）。
> 本轮又把**升品花费**整表按同一条判据重算了一遍（见上一条）。
> 现在这些都固化成了冒烟测试里的**八条断言**（所以以后不会再悄悄回来），
> 完整判据与前后对照见 [BALANCE.md](BALANCE.md) 第十五节「顺序体检」。

**器物怎么用着用着就没了？**
因为**可携带器物是有使用次数的消耗品**（需求 2：「影响弟子探索的器物有使用次数限制，
达到限制后损毁，需要重新炼制」）。17 种器物里有 **6 件**是这样：

| 器物 | 效果 | 能用几次 |
|---|---|---|
| 🪶 轻身符 | 探索速度 +20% | **12 次** |
| 👝 采灵袋 | 秘境产出 +20% | **10 次** |
| 🏮 引魂灯 | 探索伤亡率 −18% | **8 次** |
| 🚩 御兽幡 | 弟子战力 +30% | **6 次** |
| 🪞 虚空镜 | 秘境产出 +35% | **5 次** |
| 🥋 长生法衣 | 探索伤亡率 −30% | **4 次** |

- **每探索一次各消耗 1 次**（探秘境与普通探索都算），
  但**中途取消的探索不磨损** —— 消耗发生在"结算那一刻"；
- **次数归零就从库存里消失**，记事里会写「携带的 **X** 已损毁，需重新炼制」，
  卡片上显示「（已损毁，需重炼）」，加成也随之归零；
- **重新炼一件就是满次数**（同一件器物不堆叠耐久：新炼的直接覆盖旧残件）；
- ⚠️ **耐久越短的效果越强** —— 轻身符能用 12 次但只 +20% 速度，
  虚空镜只够 5 次却 +35% 产出。所以"这一程缺什么"才是该炼哪件的判据。
- 💡 顺便记住：**周天星图不是消耗品**（它不带耐久，发现概率 +3.5%，永久生效），
  想要稳定的发现加成可以走它。

**秘境怎么找？**
秘境不再是"攒够材料就自动出现"，而是**探索中发现**的：

- 派弟子探索、或让掌门出门游历，每次结算时判定一次发现；
- **普通探索也会判定发现**（见下一条）—— 而且它和探秘境**共用同一套概率与硬保底**；
- 基础概率 **15%**，而且**只有一条路能提高它：铸造并装备「🧭 寻宝宝盘」**
  （七品炼器，材料超稀有）—— 每面 **+4%**，上限 75%；
- **山门 / 通天塔 / 照天镜都不再加发现概率**（它们改成了全局产量 / 秘境产出 /
  探索速度），队伍人数和探索距离也不再折算成概率；
- 运气差也不会卡死：**连续 10 次没发现，第 11 次必然发现一处**（硬保底）。
  这个计数存在存档里，和概率公式是两条独立的机制；
- 共 **150 处秘境**，分挂在 **96 个小区域**下（每处 1~2 个，资源富集区 3 个），
  开局只有 **青石谷·药圃** 是已知的，发现后**永久固定**在地图上。

地图上每个小区域格子上会写 `秘境 已发现/总数` 就是提示。探索页顶部会实时给出三件事：
当前发现概率（与宝盘加成）、**还差几次触发硬保底**（或"下一次探索必定发现"），
以及 `探索距离 N 里 · 可达 X/96 小区域 · 已发现 Y/150 秘境`。

**为什么有的小区域点不开？**
地图上每个小区域格子的状态有三种，看一眼格子上的字就知道：

| 格子上的字 | 意思 | 能点开吗 |
|---|---|---|
| `秘境 1/2` | 境界到了，这一格的秘境可以探 | ✅ |
| **`可探查 · 秘境需X`** | **这一带能来做普通探索**，但格子里的秘境还要 X 境界 | ✅（点开只有普通探索卡片） |
| `需X` | 掌门境界不够走到这片**大区域** | ❌（会提前一个境界灰着显示，方便你规划） |

⚠️ **"能不能点开格子"和"能不能探秘境"是两件事** ——
早先这里写的是"秘境探不了就连格子都不给点"，于是**里面那条普通探索也跟着消失了**，
玩家只会以为"这一片打不开"。现在**能普通探索就能点开**，
点开之后每个秘境各自显示自己还差什么（境界 / 队伍战力 / 富集区还没开启 / 冷却中）。

另外注意：**普通探索的门槛是按「大区域」算的** —— 东部群山（炼气）整片都能做普通探索，
南疆要筑基、西漠要金丹、北境要元婴、中州要化神、无垠海要炼虚；
**不再按小区域自己的档次卡**（那曾经导致"除了最前面几个小区域，其它都点不动"）。
秘境本身的境界 / 战力 / 开启门槛**一个都没放宽**。

**普通探索是什么？和探秘境有什么区别？**
「普通探索」是**一个小区域里还有没被发现的秘境时**，对**这个区域**做的事
（需求原文就是「每个小区域在未发现秘境时只能普通探索」）。
点开一个小区域格子，如果里面还有没找到的秘境，就会出现 🔍 普通探索卡片：

| | 🔍 普通探索 | 🌌 探秘境 |
|---|---|---|
| 前置 | 该小区域还有没发现的秘境 | 该秘境已经发现 |
| 产出 | **必定**基础材料（1~2 种，数量随机）+ **30%** 稀有材料 | 按掉落池加权抽 3~6 条 |
| 产量 | 秘境的 **×0.65** | 基准 |
| 时长 | 更短（一档 66 秒 → 九档约 47 分钟） | 120 秒 → 7,280 秒（最深处约 2 小时） |
| 人数 | **1~4 人** | 该秘境的 `minParty ~ maxParty` |
| 冷却 | **无** | 90 秒 → 5,040 秒（最深处 84 分钟） |
| 伤亡 | **无**（弟子不会陨落） | 有，按战力比缩放 |
| 心得 | 秘境的**一半** | 基准 |
| 丹药 / 种子 / 图纸 | 都不掉 | 会掉 |

关键有三点：

1. **它是"开图"的唯一手段** —— 想发现新秘境、想去新的大区域，就得做普通探索；
2. **它的门槛按「大区域」算**：境界够走到那片大区（东部群山炼气 / 南疆筑基 /
   西漠金丹 / 北境元婴 / 中州化神 / 无垠海炼虚），**整片大区的小区域都能做普通探索**。
   秘境本身的境界 / 战力 / 开启门槛一个都没放宽 —— 所以你会在格子上看到
   「可探查 · 秘境需X」这种"能来、但秘境还不够格"的状态；
3. **它和探秘境抢同一批队伍名额**（**掌门亲往不占名额**）。探秘境的收益高得多，
   所以正确顺序是**秘境那边没得打的时候，再派队伍出门开图**。
   模拟器一开始把顺序反了，结果队伍全压在开图上 → 秘境收益断供 →
   弟子变弱 → 寿元变短 → 30 天结束时**弟子 0 人**（改成"没得打才开图"后回到 50 人，
   见 [BALANCE.md](BALANCE.md) 第二十八节第 26 条）。

另外，**掌门本人也能去**（卡片底部那个「掌门亲往」按钮）：
不占弟子、不占名额、不会死人，**开宗前就能出门**，代价是时长 ×1.25、基础材料减半
（稀有材料那一侧是 **30%**，与派队伍同概率；**不再扣产量**）——
见上面「掌门亲往和派队伍有什么区别？」。

> 顺带说一条容易被误会的设计：普通探索只在"**当地还有没发现的秘境**"时可用，
> 但**发现本身不限于当地** —— 弟子的见闻可以来自更远的地方。
> 我试过把发现也限制在同一个小区域内（逻辑上更贴合需求），
> 结果经济被拖垮、终盘弟子归零，最后保留全局候选池
> （见 [BALANCE.md](BALANCE.md) 第二十八节第 28 条）。
> `canSurveyRegion` 管的是"**当地能做什么**"，不是"发现只能发生在当地"。

**弟子探索能挂机循环吗？**
能。**秘境卡与普通探索卡上各有一个「循环 N 次」输入框（1~30）**，
填了之后队伍会**自己一趟接一趟地做**，不用你回来重派。四条要知道的规则：

| 问题 | 答案 |
|---|---|
| **最多几趟** | **30**（上限写死成 `MAX_EXPEDITION_REPEAT`，界面上的上限和引擎里是同一个数）。填 0 / 999 会被夹回 1 / 30 |
| **会跳过冷却吗** | **不会**。下一趟是"**原地等完冷却再出发**"——一档秘境 90 秒冷却 + 120 秒时长，循环 3 趟就是"3 趟探索 + 2 段冷却" |
| **队员会回池吗** | **不会**。整段循环期间他们一直算"探索中"，不会被别的队伍派走；次数做完或中途停下才回到空闲 |
| **中途会停吗** | 秘境会死人：如果伤亡到**凑不满最少人数**（低于 `minParty`），循环就停在那里。普通探索没有伤亡，所以只要队伍里还有人就会继续 |

⚠️ **它解决的是"排不上队"这件事的一半**：
循环让**一支队伍**长期有事做，而**起步队伍从 1 支提到 3 支**（一品宗门 3 队）让
**更多队伍同时有事做** —— 两件事叠起来，才有"弟子一直在外面、心得一直在涨"。
⚠️ **实测读数只反映了后者**：模拟器的 AI 目前**没用循环探索**（它仍然一趟一趟地派），
但"首次秘境探索"已经从 9 小时 3 分提前到 **3 小时 38 分**（那是 3 支队伍的效果）。
循环探索本身的正确性由冒烟测试那 11 条断言守着（含两条搭场景的检查：上限 30 / 夹取 /
循环次数写进队伍 / 队员保持探索中 / 做完一趟剩 N−1 / **负进度** / 队员不被放回 /
只做一趟不重排 / 单趟后队员恢复空闲 …）。
详见 [BALANCE.md](BALANCE.md) 第六节末尾与第八节「循环探索」。

**建造队列怎么用？名额怎么加？**
「洞府 → 建造」里每个建筑多了一个「**排队**」按钮，把想盖的东西按顺序排进去，
**资源一到就自动开工** —— 挂机和离线回来时收益最大。
（**唯一类建筑建好之后，建造与排队按钮都会消失** —— 见常见问题与
[BALANCE.md](BALANCE.md) 第三节：它不会再建第二座，所以不该给你一个按钮。）
队列面板在「**建筑**」页右栏（**可以点标题栏收起**）：

- **名额**：初始 **3** 个 → 建 **天工院** **+1** → 天工院的三级**特殊升级**各 **+1**，
  满配 **7** 个（「名额来源」那一栏会把每一步的点亮情况列出来）；
- **天工院**（🏗）**金丹期**解锁、**唯一**、不需要钻研；
  三级升级是 **扩建料场 / 增设工坊 / 请动仙匠**，价格跨三个数量级
  （500 万 → 5 亿 → 500 亿灵气）；
- **队列语义**：队列里第一项**门槛没到或资源不够就原地等着，不会跳过** ——
  面板会直接写出它**缺什么**（缺哪几样材料、还差哪个技术 / 图纸 / 境界）；
- **一次只开工一座**（连建会让账目变得难预测）；
- 队列内容与天工院升级等级**都会存档**；读档时认不出来的建筑 id 会被丢弃，
  升级等级会被夹回 0~3。

> **名额不是越多越好，一次挂一个目标更稳。** 模拟器试过把 7 个名额一次填满，
> AI 同时朝 6 个方向花钱，把灵石抽干 → 招收弟子停摆 → 弟子陆续老死 → **归零**。
> 名额的意义是"**挂机时能提前排几步**"，不是"并行撒钱"
> （见 [BALANCE.md](BALANCE.md) 第二十八节第 7 条）。

**为什么我打不了某个秘境？**
按顺序检查四件事（界面上会直接标出是哪一条）：

| 原因 | 怎么解决 |
|---|---|
| 还没发现 | 去探索（普通探索或探已经发现的秘境都行）；或等连续失败攒到 10 次，硬保底会必然开出一处 |
| 小区域到不了 | 境界不够 —— 每个小区域都有 `requiresRealm`（见探索页地图）；**资源富集区还要再高 4 档** |
| 宗门品阶不够 | **第 6 档起**（中州一带）要 2 品宗门，此后依次是 3 / 5 / 7 品；第 1~5 档不限。⚠️ 实际门槛会**按"这个境界最多能有几品宗门"夹一次**（见下面那一条） |
| **🔯 尚未开启** | 富集区里的秘境发现之后还得**花资源立阵眼**（灵气 / 灵石 / 灵矿 + 阵枢），卡片上有花费清单与「耗费资源开启」按钮 |
| **冷却中** | 每处秘境探索完都要等一会儿才能再探，卡片上有倒计时（越深越长，最深处 84 分钟） |

另外队伍人数要在 `minParty ~ maxParty` 之间，还有**弟子自己的境界**：
**秘境的 `minRealm` 现在就等于「它所属大区域的解锁境界」** ——
东部群山（炼气）名下的秘境炼气弟子就进得去，南疆（筑基）要筑基、西漠（金丹）要金丹、
北境（元婴）要元婴、中州（化神）要化神、无垠海（炼虚）要炼虚。
也就是说**同一个大区里所有秘境的弟子门槛都一样**（这跟以前"松一级"的写法不同了），
所以在大区内部真正决定"能不能派"的是**战力比、宗门品阶与冷却**。

**为什么有的秘境写着「需要筑基期」却进不去？**
因为**秘境身上挂着两个门槛，而它们量的是两件事**（这一点旧版真的出过问题）：

| 卡片上写的 | 取自 | 例子 |
|---|---|---|
| `筑基期以上`（推荐战力旁边那一行） | **大区域**的解锁境界 | 东部群山 0 / 南疆 1 / 西漠 2 / 北境 3 / 中州 4 / 无垠海 5 |
| `需 N 品宗门`（按钮点不动时给出的理由） | **小区域档次** | 6 档 2 品 / 7 档 3 品 / 8 档 5 品 / 9 档 7 品 |

而**宗门每一品自己也有境界要求**（一品金丹、二品化神、三品炼虚、五品合体、七品大乘……）。
旧版把这两个门槛直接拼在一起，于是出现了「**龙骸血池（需筑基期）却要求 2 品宗门，
而 2 品宗门本身要化神期**」这种条目 —— 界面写着"筑基期"，实际得等到化神期，
**全库一共 67 处**。

现在这两个门槛会**按"这个境界最多能有几品宗门"夹一次**
（`capSectLevelByRealm`，见 [BALANCE.md](BALANCE.md) 第八节）：
**一处秘境声明自己在境界 R 开放，就不可能要求一个 R 时根本达不到的宗门品阶。**
所以：

- 你**看不到"写着筑基期却要化神期宗门"**这种组合了（夹取只会把门槛**降低**）；
- 如果你仍然进不去，看**按钮上给出的那一条**（`需先能抵达X` / `需N品宗门` / `冷却中`）——
  那才是真正的当前门槛；
- ✅ **建筑那边同一族的 8 处也已经夹过了**（规则完全一样：夹到"自身境界最多能有几品宗门"）：

  | 建筑 | 自身境界 | 宗门门槛：旧 → 新 |
  |---|---|---|
  | ⛩ 洞天 / 🏛 仙府 / 🌿 药王圃 / 🏬 万宝楼 / 🗼 通天塔 | 化神期 | **→ 2 品** |
  | 🪴 灵田阵 | **炼虚期** | 5 → **4 品** |
  | 📖 讲道堂 / 🪷 悟道池 | 元婴期 | **→ 1 品** |

  ⚠️ 副作用一条：建筑的可见性规则是「**门槛提前一级显示**」，
  所以**洞天现在初始 1 品宗门就看得见**（灰着并标出还差什么）——
  那是刻意的"让你看到下一步目标"，不是 bug。
  还留在"差得多就看不见"那一档的只剩**灵田阵（4 品）**。

**富集区的秘境为什么探不了？**
因为它**要先花资源"开启"**（需求 1：「资源富集区的秘境开启需要花费一定资源」）。
发现之后卡片上会写「**🔯 尚未开启**」并列出花费，点「**耗费资源开启**」把阵眼立起来才能派队伍。

| 问题 | 答案 |
|---|---|
| **哪些要开？** | **只有资源富集区里的 18 处**（6 处富集区 × 每处 3 秘境），其余 132 处发现即可探 |
| **要花什么？** | 灵气 + 灵石 + 灵矿 + **🔯 阵枢**（阵枢是要自己合成的进阶资源）。越深越贵：第 5 档 **55 个阵枢**，第 9 档 **1,072 个**；**特产秘境还要再 ×2.5** |
| **能不能全开？** | 18 处全开要 **7,364 个阵枢** —— 比三座宗门大阵的 5,850 还多，所以是"**挑着开**"，不是清清单 |
| **为什么我只开成了一两处？** | ⚠️ **因为要先"发现"才能"开启"** —— 没探索出来的地方连阵眼都立不了。所以"付得起就开"也会被卡住（模拟器 30 天里只开成了 1 处，**这是设计，不是开启功能没生效**） |
| **点不动是什么原因？** | 卡片上会直接写：「尚未发现此秘境」/「已经开启」/「资源不足」 |

> 💡 **所以富集区的正确打开顺序是**：先在那一片做普通探索把秘境**找出来** →
> 攒够阵枢（元婴期 + 营造之术之后就能合成）→ 再开。
> 这也是"想动富集区，先去合成"这条链路的由来。

**秘境为什么要有冷却？**
需求明文要求的（「每次探索后需要隔一段时间才能再次探索」）。
作用是不让你反复刷同一处 —— 想持续拿材料就得去发现新秘境，
这正好和地图的设计配成一对。
（注意**普通探索没有冷却**，所以"秘境都在转"的那段时间也有活干。）

**「建筑怎么建不了 / 是灰的」？**
建筑的解锁条件共有**六层**，全部满足才能建造：

| 门槛 | 怎么满足 |
|---|---|
| 资源门槛 | 曾经拥有过若干资源（一次性，永久记录） |
| 开宗 | 宗门类建筑要求先开宗立派（掌门大殿 / 山门只需这一条） |
| **技术** | 去「修行 → 钻研」把对应技术钻出来（要付材料 + 等 20~400 秒） |
| **图纸** | 只能从**秘境探索**或**商行**获得，钻研不出来 |
| **前置建筑** | 比武台 / 武技阁 / 功法殿 / 通天塔都要求先建**掌门大殿**；三座宗门大阵是一条链：**山门 → 🛡 护山大阵 → ✨ 周天星斗大阵 → 🌀 混元无极阵** |
| 境界 / 宗门品阶 | 掌门修到对应境界、宗门升到对应品阶 |

界面会提前一级显示并标出还差什么，鼠标悬停按钮也能看到原因。
**只有 10 座资源设施、茅屋、储物袋、🛖 静室不需要钻研** —— 所以开局永远不会卡死。
8 张图纸只用来解锁**加成类**建筑，拿不到只是慢一点，不会玩不下去。

**「境界够高却建不了须弥洞府」？**
它额外需要「须弥之法」这门技术，而要钻研须弥之法得先有 **20 星辰砂**。
这是刻意设计的门槛：**化神期的消耗**（末层参悟 6,272 万灵气、突破炼虚要 1,200 万）
远超「只有储物袋 / 藏宝阁 / 灵脉库房」时的 532 万上限，
所以必须趁化神期把须弥洞府建起来，这门技术也就绕不开。
星辰砂开宗前**只能靠个人游历**获得（烈焰裂谷每趟 2 颗、寒泉幽谷每趟 8 颗，
都不是必掉），开宗后弟子秘境也能拿到：它从**第 3 档（金丹期）**起就进了掉落池
（`ore` 路数的秘境给得最多），越往深处给得越多。
**西漠的资源富集区「星陨深渊」里那处特产秘境「坠星渊底」是它最稳的来源** ——
星辰砂在那里必定掉落、数量还 ×3（不过那是第 7 档，要炼虚期才够得着）。

**资源显示"已满 · 产量全部溢出"是什么意思？**
灵气到了储存上限，继续产出就白白浪费了 —— 去「洞府 → 建造」的储物建筑分组里
建更高级的仓库。灵木灵矿这类副资源标黄显示"已满"只是提醒，
它们的容量余量很充足，不构成问题。

资源栏里**五种资源**每一格下面还有一行**满仓倒计时**（"还有多久装满"），
按 `(上限 − 当前) ÷ 每秒产量` 算出来：已经满了写「**已满**」、
当前没有产量写「**无产出**」、上限为 0 的写「**无上限**」、
超过 100 天的写「**很久以后**」—— 所以它不会用一个 ∞ 糊过去。
（材料不设上限，它们的卡片上写死的就是"无上限"那一句，不走这个倒计时。）
挂机之前扫一眼这一行，就知道回来时哪几样已经溢出了。

**季节和天象是什么？会不会影响我刷材料？**
天上一直在变，而且两者都会直接改产出。但**只影响资源与基础材料**：

- **四季**每 **120 真实秒（2 分钟）**轮转一次（春 → 夏 → 秋 → 冬），每一季**同时有加成和减益**：
  春 灵草 +45% / 寒玉 −25%，夏 灵气 +30% / 寒玉 −40%，
  秋 灵矿 +35% / 灵气 −10%，冬 寒玉 +50% / 灵草 −35%。
  没有哪一季是纯粹的好 —— 所以不存在"等到那最好的季节再干活"这种最优解。
- **天象**每约 **40 秒**判定一次（40% 概率出现），持续 **45~60 秒**，共十条，
  分**吉 / 凶 / 双刃**：紫气东来是全局产量 +40%，灵雨是灵草灵木各 +60%，
  血月当空让妖丹翻倍但弟子修行 −15%，弥天大雾让探索速度 −45%。
- **稀有材料（月华露 / 星辰砂 / 太阴玄晶 …）完全不吃季节加成** ——
  它们来自秘境深处，不该被地表气候左右。所以什么时候想刷都能刷，
  不存在"这一年白过了"这种事。
- **天象不会提高发现秘境的概率**（那条线只有寻宝宝盘能碰），
  **也不会让弟子死得更多** —— 这两条是刻意的，都写进了冒烟断言。
- 想囤什么就看**页头右上角**（`第 N 年 · X季 · 今年 N%`）；
  完整面板在「修行」页（当前季节进度条、天象详情、四季与天象图鉴）。
  ⚠️ 原来**左侧资源栏下面那一行常驻条**（纪年 + 季节 + 天象 + 倒计时）**已经删掉了** ——
  需求要求"资源展示界面最底下不要再挂纪年这些东西"，所以纪年搬去了页头。
- **四季现在完全由纪年推导**：一年 = 现实 8 分钟，所以一季就是 **2 分钟**
  （以前一年只有 12 秒，一季只好单独定成 90 秒 —— 那条偏离本轮已经取消）。
  天象仍然按**真实秒**计（每 40 秒判一次、持续 45~60 秒）：它是"突发天气"，不是"节气"。

**突破失败后一直不能突破？**
元婴期起突破失败会「道伤缠身」，界面顶部和境界面板都会显示剩余时间，
期间无法再次突破且产量下降。等计时走完即可 —— 也可以建几座**雷池**
（持有雷池图纸后，每座永久 +3%）。
炼气 / 筑基 / 金丹期没有这个惩罚。
另外：如果**恶行值很高**，突破还会额外挨「天雷之罚」（最多 −35% 成功率），
**参悟小境界也会被打断**（灵气照扣、2 分钟道伤）——
所以作恶的代价是"修得慢"，不是"修不了"（成功率有 15% 的下限）。

🆕 **但本轮之后更常见的"点不动突破"是另一回事：没有丹。**
需求 9 起，**大境界突破必须服一颗对应的境界丹** ——
仓库里没有时按钮是灰的，面板上会直接写「**需化神丹（丹房炼制，或秘境掉落）**」。
规则细节：
- **丹药补足差额的 62%，成功率上限 95%**（原来是一个固定的 +35%、上限 98%）；
- **「失败后累积保底成功率」已经删掉** —— 所以不能再靠"反复撞"过，
  每一次尝试都要花一颗丹（**失败也照扣**）；
- 低境界（炼气 / 筑基 / 金丹）失败仍然没有别的代价（灵气全额返还、可立即再试），
  元婴期起才留下道伤；
- **弟子的突破同理**（见常见问题「弟子卡在瓶颈了？」）。

**出门游历会掉产量吗？**
**不会 —— 这条设定已经删掉了。** 旧版里掌门（无论游历、独自探秘境还是亲自普通探索）
出门期间会让**全局产量 −45%**，理由是"无人监管家里"。
实际玩下来它只做了一件事：**让人不敢出门** ——
出门本来就有代价（时间），再叠一层**看不见的**减产，玩家往往是事后才发现自己亏了。

现在出门的代价只有两条，而且都是看得见的：

- **时间**：一趟 90 秒 ~ 1,800 秒（掌门这期间干不了别的）；
- **掌门亲往秘境的总量 ×0.45、掌门亲往普通探索的基础材料减半**（这才是"一个人搬不动"）。

⚠️ **注意区分另一条同名惩罚**：**道伤**（突破失败后）**仍然会减产 25%**，
界面顶部和境界面板都会显示剩余时间 —— 那是"被打伤"，与出门无关。
🆕 顺带一条：**"进行中"那一块现在三种出行方式都会画进度条**
（掌门游历 / 掌门独自探索 / 掌门亲自查探），见常见问题「掌门出门了，怎么看还有多久回来？」。

**弟子怎么修行得越来越快？**
七个来源现在**在同一个加算池里**，全部相加（不再是相乘），
外加**一个乘在最外面的"在外历练"系数**：

```
修行速度 = 资质 × (1 + 功法殿 + 讲道堂 + 静室 + 悟道石 + 聚灵阵 + 大比 + 心得)
           ↑ 乘在最外面
🏃 在外的弟子：上面的结果再 ×1.5（需求 10）
```

- **资质** 0.25 ~ 1.00（乘在最外面）
- **宗门建筑**：功法殿 **+8%/座**（上限 10 座 = +80%）、讲道堂 **+5%/座**（上限 10 座 = +50%）
- **两座初期修行建筑**：🛖 静室 **+3%/座**（上限 12 座 = +36%，
  **600 灵气起、零门槛，开局就能盖**）、🪨 悟道石 **+6%/座**（上限 8 座 = +48%、筑基期）
- **聚灵阵也算进来**：**加成 = 2% × √座数**（收益递减 ——
  4 座 +4%、25 座 +10%、100 座 +20%、400 座 +40%），见下面「为什么聚灵阵越多弟子越快？」
- **大比**：生效期间 **+50%**（原来是乘算 ×2）
- **心得**：每点 **+0.5%**，上限随掌门境界增长（炼气 30 → 大乘 240 → 渡劫 270 点）
- 🆕 **在外历练（需求 10）**：弟子只要**状态是"探索中"**，修行速度 **×1.5** ——
  注意它是**乘在加算池外面的**，所以不会和建筑加成互相放大；
  界面上的"还要几年"已经把这 50% 算进去了。

所以「多派弟子去探索攒心得」「多建功法殿 / 讲道堂 / **静室 / 悟道石**」
「多盖聚灵阵」「把大比开着」现在是**四件都要做的事**，
而且**"让队伍一直在外面"本身**也第一次成了一件有修行收益的事。

> **为什么要改成加算？** 旧设计里心得和建筑是**两个乘区**、大比又是建筑那一项里的乘算 ×2，
> 三者互相放大：只算"建筑 + 大比"就是 `(1 + 1.2 + 1.5) × 2 = ×7.40`，
> 再乘上 `资质 × (1 + 心得)`，**结构上限能到 ×17.35**。
> 合并成一个加算池、并把两座建筑降了一轮之后，那一组落在 **×2.80**。
> ⚠️ **后来又往这个池子里添了三格**（静室 +36% / 悟道石 +48% / 聚灵阵）——
> 所以"天花板"这个说法要从两个口径看：
> **冒烟测试钉的仍然是"功法殿 + 讲道堂 + 大比 = ×2.80"那一组**
> （含满心得 ×4.15），而**把新建筑也算满是 ×3.64 / ×4.99**，聚灵阵再往上叠，
> 最后再乘上"在外 ×1.5"。
> 好处是它们**进的是同一个加算池**，所以添三格只把那个数抬了 30%；
> 如果它们是乘算的，同样三格会变成 ×5.63（见 [BALANCE.md](BALANCE.md) 第十三节）。

**为什么聚灵阵越多弟子越快？**
因为聚灵阵就是"宗门灵气的根"，而**它的"等级"在游戏里就是"你盖了几座"**
（它没有 1 级 / 2 级的说法）—— 所以本作的规则是：

```
聚灵阵给的修行加成 = 2% × √座数       ← 注意是开方，不是"每座 +2%"
```

| 座数 | 4 | 25 | 100 | 400 |
|---|---|---|---|---|
| 加成 | +4% | +10% | +20% | **+40%** |

⚠️ **为什么非得开方：第一版写成线性"每座 +2%"时，模拟器里直接炸了** ——
聚灵阵是**全表最便宜的设施**（15 灵气起、价格只按 1.15 涨），
AI 为了灵气盖了**两百多座**，修行倍率被推到 **×6.72**；
而这条曲线本来是设计在 **×4 出头**的（正因为如此，更早才把宗门大比从 ×2 压成 +50%）。
换成开方之后是 **×3.89**，回到设计区间。
**一句话：往一个"可以无限盖的便宜建筑"上加百分比加成，等于往全局曲线上加一个不受控的变量。**
（冒烟测试为此守着四条断言：「越多越快」「十座 +6.3%」「收益递减」「400 座也只 +40%」。）

**初期怎么加快弟子修炼？**
按"现在就能做"的顺序，一共五件事：

| 做什么 | 怎么来 | 收益 |
|---|---|---|
| 🛖 **盖静室** | **600 灵气 + 150 灵木** 起，**一个门槛都不用**（连开宗都不需要） | 每座 **+3%**，12 座 = **+36%** |
| ☯ **多盖聚灵阵** | 开局第一个建筑，15 灵气起 | `2% × √座数`（顺手就把灵气产量也推上去了） |
| 🧭 **多派弟子探索** | 见「弟子探索能挂机循环吗？」 | ① 弟子**心得**每点 +0.5%，上限 240~270 点（= **+120% ~ +135%**）；② 🆕 **在外的弟子修行速度再多 50%**（需求 10） |
| 🪨 **盖悟道石** | **筑基期**解锁，1.2 万灵气 + 1,200 灵石 + 2,500 灵木 | 每座 **+6%**，8 座 = **+48%** |
| 📜 **钻研传法之道 → 盖功法殿** | 要开宗 + 钻研 + 掌门大殿 | 每座 **+8%**，10 座 = **+80%** |

⚠️ **注意"出门"这一条同时给它两笔收益**（心得 + 在外的 50%），
所以它是这几件里最大的一块 —— 这也是更早一轮把**起步队伍从 1 支提到 3 支**的原因
（见常见问题「弟子探索能挂机循环吗？」与「弟子在派遣期间修行更快吗？」）。

⚠️ 🆕 **但本轮之后要先解决一件事：弟子的突破要有一颗对应境界丹**（需求 9）。
修为攒满而仓库没丹时他会停在瓶颈 —— 所以"加快修炼"的前提是
**炼丹线跟得上**，否则练得再快也只是在瓶颈前面排队
（见常见问题「弟子卡在瓶颈了？」）。
详见 [BALANCE.md](BALANCE.md) 第十三节。

**大比什么时候开？我要手动点吗？**
只需要建好**比武台**再点一次「开启大比」，之后就自动循环了。
按游戏时间是十年一次、每次加速持续一年；换成真实时间就是
**每 80 分钟一次、每次加速 8 分钟**（因为纪年是一年 = 8 分钟，十年 = 4,800 秒）。
**加成占空比仍然是 10%**（8 分 / 80 分），所以长期收益和以前一样 ——
只是"节日"之间的间隔变长了。
生效期间是实打实的 **+50% 修行速度**，但因为改成了加算，
它要加在"1 + 满配修行建筑"这个分母上 ——
⚠️ 这个分母本轮变大了（功法殿 + 讲道堂 + 静室 + 悟道石 = **+214%**，聚灵阵还会再叠），
所以折算长期收益从上一版的约 **+2.2%** 掉到约 **+1.6%**。
拆掉比武台会自动停办，但已经拿到的加速不会取消。

**弟子心得的上限是多少？**
**跟着掌门境界一起长**：`30 + 境界 × 30`，也就是炼气期 30 点、化神期 150 点、
大乘期 240 点、**渡劫期 270 点**。每点 +0.5% 修行速度，
所以满上限时是 +15% → **+135%**。
弟子面板与宗门页的心得排行都显示成 `心得 45/270` 这种"当前/上限"的形式。

> 早先上限写死 100 点（+100%），有两个毛病：到顶后心得不再增长（是个墙），
> 而秘境从 8 处扩到 44 处（现在是 150 处）之后单次探索给的心得被摊薄，实测最高只到 52 点 ——
> 上限既摸不到又卡在中间。现在上限跟着境界长。
>
> ⚠️ **这个数在八版之间来回摆过，而且最新两版给出了一组非常有用的对照**：
> 更早一版实测是「最高 **240** · 中位 **240**」——**中位数也顶到上限**，
> 于是终盘所有弟子的修行加成一模一样；
> 接着一版降到「最高 240（= 上限）· 中位 **173**」——区分度回来过一次；
> 再上一版又回到「最高 240 · 中位 **240**」——再次顶格；
> 然后依次是 **232 → 185 → 179 → 76 → 270**。
> （八版中位：240 → 173 → 240 → 232 → 185 → 179 → **76** → **270**。）
> 🆕 **最后那两格是同一局游戏，只差"观测窗口"**：
> - **只跑 24.6 天**时是「最高 240 · 中位 **76**」—— 人口刚暴涨，大量新招的
>   低境界弟子还没攒够出勤，把中位拉得很低；
> - **跑满 30 天**时是「最高 **270** · 中位 **270**」—— **双双顶到上限**，
>   区分度归零。
>
> 📌 **所以这个读数要这样读**：它不是一个"结构指标"，而是一个**对窗口极度敏感的即时量**。
> 想让它有意义，得固定窗口（或者干脆换个指标，例如"心得的百分位分布"）。
> （⚠️ 报告不给出勤次数，所以上面两版的解释都只是"最合理的解释"。）
> 能确定的是：心得会不会顶格取决于"**出勤次数 × 每次给多少 × 观测了多久**"，
> 而不是心得上限本身（见 [BALANCE.md](BALANCE.md) 第二十六节读数 5 与第二十九节第 4 条）。
> 顺带一个小细节（**更早暴露、已经修好并验证**）：**心得字段曾经可以超过上限**
> （出现过 `250 > 大乘期的 240`），因为只有大比与建筑事件那几条奖励路径夹了上限 ——
> 效果不受影响（取的是 `min(心得, 上限)`），只是界面上会出现超上限的数字。
> 现在三条来源统一走 `disciples.addInsight` 自动夹上限，
> **实测"最高心得"每次都正好停在上限本身**（240 或 270），
> 界面不会再出现 `心得 256/240`。

**商行多久刷新一次？**
**60 真实秒**（就是 60 秒，和游戏日历无关）。
需求原文写的是「每个游戏时间一个月刷新一次」，但那条**没法照字面实现**：
早期一个游戏月只有 1 真实秒（会变成每秒重摇的老虎机），
而现在一个游戏月约 39.5 秒，"60 个游戏月"会算出 **39 分钟**一次。
所以本轮把它从日历里彻底拆出来，直接写成
`src/game/content/shop.ts` 的 `SHOP_REFRESH_SECONDS = 60`。
（对比一下：**大比仍然跟着日历走**，因为它的收益只取决于占空比，
80 分钟一次和 2 分钟一次的长期收益完全一样。）

**商行怎么没有稀有材料 / 稀有种子？**
刻意的。商行只卖资源、基础材料、基础材料种子、**进阶资源（应急）**和图纸；
稀有材料与稀有种子只能靠探索（个人游历或弟子秘境）获得，
否则探索就没有存在意义了。

> 注意区分两类"不常见的东西"：
> **稀有材料**（月华露 / 星辰砂 / 太阴玄晶 …）**永远不卖**，因为它们代表探索的价值；
> **进阶资源**（灵液 / 精金 / 阵枢）**会卖**，因为它们是"自己做出来的东西"，
> 商行只是多一条应急渠道 —— 而且价格明显贵于自己合成（见「进阶资源怎么来？」）。

**种植为什么不能自动收获？**
挂机 8 小时后自动收获会把几十块地的产出一次性塞进材料栏，
玩家完全看不到发生了什么。所以收获是手动的，但每块地都能单独点，
也有**一键收获** —— 既不烦人，也让每次回来都有事可做。
急着要材料的话可以用**催熟**（灵气便宜推 90 秒，灵石贵推 300 秒）。

**游戏的随机结果每次一样吗？**
不一样。游戏运行时用的是 `Math.random`（真随机），存档里也不记录任何种子。
只有 `pnpm smoke` / `pnpm simulate` 这两个分析工具会用固定种子，
这样回归测试和数值对比才有意义。详见上文「三个设计约束」。
（顺带一条纪律：这两个工具里的每一个随机调用都必须**显式传**种子随机源 ——
这条纪律**一共漏了三次**（修行、派队伍、时空穿梭），三次都已修好，
现在连跑两次逐行一致 ✅；症状都是"同一份种子连跑两次对不上"，见上文第 2 条。）

**旧存档能继续用吗**
能，一路升到 v4 都不会丢东西：

- **v1** 存档会自动迁移：设施、境界、道韵、灵气全部保留，
  v1 里的通用「丹药」会折算成等量的聚气丹。
- **v2** 存档读入后，新增的字段（技术、图纸、种子、地块、商行货架、
  自动合成档位、游历状态）都会用默认值补齐。
- **v3** 存档里「靠材料解锁的秘境」会直接按**已发现**继承，
  并补上新增的冷却表、大比与宗门事件的计时字段；
  弟子会补上 `insight`（旧的按 0 算）。
- **v4** 存档会补上**建造队列**（`bq`）、**天工院升级等级**（`tl`）、
  **善恶值**（`ka`）、**待选遭遇**（`pe`）、**遭遇判定计时**（`et`）、**遭遇倒计时**（`ed`）、
  **掌门出门的类型**（`personalTravel.kind` —— 现在有三种值：
  `travel` 游历 / `realm` 独自探秘境 / **`survey` 亲自普通探索**；
  **旧的、没有 `kind` 的存档一律按"游历"处理**）、
  **感悟七条道的阶数**（`en`）、**正在感悟的道**（`eg`）、
  **空间戒指数**（`sr`）、**上次穿梭时间**（`lj`），
  以及本轮新增的两个：**富集区秘境的开启记录**（`or`）、
  **可携带器物的剩余次数**（`gc`）。
  默认是「空队列 + 0 级 + 中立（善恶值 0）+ 没有待选遭遇 + 七条道 0 阶 + 0 枚戒指 +
  从未穿梭 + 一处富集区都没开 + 可携带器物按满次数算」。
  读档时**认不出来的建筑 id、遭遇 id、道名与秘境 id 都会被丢弃**，
  升级等级会被夹回 0~3；队列比名额长也不会报错（多出来的项只会一直排在后面）。
  ⚠️ **`gc` 的清洗有一条额外的规矩**：只认"**还在库存里、而且确实可携带**"的器物，
  次数夹到 `0 ~ 满次数`；**不在库存里的器物不会留下耐久记录** ——
  所以"器物用坏了"这件事本身是记在库存（`artifacts`）上的，不靠 `gc` 表达。

> ⚠️ **地图重做之后，旧存档里"已发现的秘境"会全部回到只剩开局那一处。**
> 旧版秘境 id 形如 `iceValley_r0`（挂在上一个区域体系下），
> 现在的小区域 id 是 `<大区域>_<下标>`、秘境 id 是 `<小区域>_r<rank>`
> （例如 `northReach_15_r0`），两套 id **没有一一对应关系**。
> 读档时认不出来的 id 会被丢弃（`SECRET_REALM_MAP[id]` 查不到就不认），
> 于是 `discoveredRealms` 只剩 `STARTER_REALM_ID`（青石谷·药圃）——
> **需要重新探索把地图找回来**。
>
> 这是地名体系整体换过一遍的必然代价：**不会损坏存档、也不会卡死**
> （150 处秘境都还在，抽回来只是时间问题），但这一条值得提前知道。

> ⚠️ **只有一样东西会丢：旧的发现保底进度。**
> 老存档里的存档键 `dp` 是"累积保底概率"（0~0.5 的小数），
> 和现在的"连续失败次数"（0~10 的整数）**语义不同**，没法换算，所以直接丢弃。
> 代价只是少一点保底进度 —— 反正最多再失败 10 次就必然发现一处，不会卡死。

**想把游戏改快/改慢**
所有数值集中在 [`src/game/content/`](src/game/content/)，
改完跑 `pnpm simulate`（5 个种子 × 30 天）立刻能看到新节奏。
**它是可复现的**（同一份代码连跑两次逐行一致，只差"总耗时"），
所以改数值前后的对照可信；但**每个种子之间本来就有波动**
（终盘那一段尤其明显，合体期 ±40%），所以差异要跟波动一起看。
对照表见 [BALANCE.md](BALANCE.md) 第二十七节。
